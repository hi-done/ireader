# Q6-20261020 按钮主题色是什么及由什么控制

## 问题

IReader 中按钮的主题色（品牌强调色）是什么颜色，由哪些设置、逻辑与样式控制？

## 回答

### 结论

按钮的「主题色」是苹果系统蓝，集中定义为三个 CSS 变量：

- 浅色主题：`--brand: #007aff`（悬停 `--brand-hover: #0063cc`、浅底 `--brand-soft: #e8f1fe`）
- 深色主题：`--brand: #0a84ff`（悬停 `--brand-hover: #409cff`、浅底 `--brand-soft: #0b2440`）

但品牌色**不是所有按钮的底色**，而是按按钮层级选择性使用：只有主按钮 `.primary` 用它填充，普通按钮走中性色变量（`--surface` / `--border` / `--text`）。全局样式表头部注释即写明「品牌色仅用于主按钮与关键状态」。

### 按钮三级体系与颜色来源

| 层级 | 选择器 | 背景 | 描边 / 文字 | 是否用主题色 |
|---|---|---|---|---|
| 主按钮 | `button.primary`、`.btn-primary` | `--brand` | 描边 `--brand`、字 `#fff`；悬停 `--brand-hover` | 是 |
| 普通按钮 | 默认 `button` | `--surface`（悬停 `--surface-2`） | 描边 `--border`、字 `--text` | 否 |
| 危险主按钮 | `button.danger-fill` | `--danger` | 描边 `--danger`、字 `#fff` | 否（用危险色） |
| 文字按钮 | `button.ghost` | 透明 | 字 `--text-secondary`，悬停 `--text` | 否 |

主按钮的实际使用位置包括：文库「导入书籍」、统计页「重试」、对话框「确定 / 重新定位 / 创建并移入」、设置页更新「下载 / 重启并安装」等。

此外还有两处按钮与控件消费品牌色：

- 键盘焦点环：`button:focus-visible` 为 `outline: 2px solid var(--brand)`。
- 输入框 / select 聚焦：描边 `--brand` + `0 0 0 3px var(--brand-soft)` 光晕；自绘下拉的悬停高亮为 `--brand` 底 + 白字，选中勾选为 `--brand` 色。

### 由什么控制（四层链路）

1. **用户设置**：`Settings.theme` 类型为 `'light' | 'dark' | 'system'`，默认 `'system'`，随其他设置经 IPC 持久化到 SQLite 的 settings 表。设置页「主题」下拉提供「跟随系统 / 浅色 / 深色」，`@change="save"` 后调用 `settingsStore.patch`。
2. **主题解析**：`theme.ts` 的 `resolve()` 在 `system` 时读取 `matchMedia('(prefers-color-scheme: dark)')`；`applyTheme()` 把结果写入 `document.documentElement.dataset.theme`（`light` / `dark`）。
3. **实时跟随**：`initTheme()` 在 App 挂载后调用一次——先按系统外观上色避免闪错主题，随后监听系统深浅变化（仅 system 模式）与 `settings.theme` 变化（`watchEffect`）实时重刷。
4. **样式消费**：`style.css` 维护两套令牌——`:root`（浅色）与 `:root[data-theme='dark']`（深色）。按钮、焦点环、输入框、下拉、图表、更新进度条等全部通过 `var(--brand*)` 取值，因此切换主题时蓝色在 `#007aff` 与 `#0a84ff` 之间自动切换。

结论：主题色不可由用户自由配置——设置里只有三态主题，没有自定义强调色字段；控制点是「主题三态 + 两套 CSS 令牌」。

### 例外：阅读器页面的按钮

阅读页恒定纯黑、不受主题影响，其顶栏与控制条按钮不使用品牌色，而是透明底 + `rgba(255, 255, 255, 0.4)` 半透明白描边 + 白字（PDF 与 EPUB 两页同款）；顶栏缩放下拉组件也通过 `--select-*` 变量覆盖成同一外观。品牌色仍出现在阅读外的关键状态上，例如更新进度条填充、统计页图表与排行强调（`var(--brand)` 渐变）。

### 事实与推断

- 事实：上述变量值、选择器、调用链均来自当前代码（见「相关代码」）。
- 推断：项目刻意把品牌色限制在「主按钮 + 关键状态」，普通按钮保持中性以避免界面大面积蓝。若未来要支持自定义强调色，只需在 `applyTheme` / `:root` 注入 `--brand` 系列变量即可覆盖，无需改按钮样式；当前不存在这类设置项与代码。
