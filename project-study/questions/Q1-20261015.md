# Q1-20261015 阅读器翻页功能的实现机制

## 问题

IReader 项目中阅读器的翻页功能是如何实现的？

## 回答

IReader 有两条独立的翻页链路：**PDF 走自研 Canvas 阅读器（页组切换 + 仿真纸张卷曲动画）**，**EPUB 走 epub.js rendition 驱动（无卷曲动画）**。阅读路由入口按书籍格式分发：EPUB 渲染 EpubReaderView，其余走 PDF 阅读器（`src/views/ReaderView.vue` L2-3）。

### 一、PDF 翻页

**1. 翻页单位是「页组」（Spread），不是单页**

- `src/services/spread.ts` 的 `buildSpreads()`（L27-51）：单页模式每组 1 页；双页模式每组 2 页，且封面可单独成页（受设置 `coverSinglePage` 控制）。
- 组内显示顺序按阅读方向镜像（`toDisplayOrder()` L54-59）：LTR（韩漫）第 1 页在左；RTL（日漫）反转，第 1 页在右。
- 模式/方向切换时用 `remapSpreadIndex()`（L71-79）重新计算新页组索引，保证定位到「包含当前页码」的页组，不跳回开头。

**2. 导航状态机（`src/stores/reader.ts`）**

- 核心状态：`spreads`（页组数组）+ `currentIndex`（L22-23）。
- `next()/prev()` 就是 `goTo(currentIndex ± 1)`，越界时忽略（L77-89）。
- `setMode()` / `setDirection()` 重建页组并保持当前页码（L57-69）。
- 每次翻页 `scheduleSave()` 防抖 1 秒落盘进度；`close()`（换书/退出）时立即 `flushProgress()`（L91-110、L112-120）。

**3. 五条输入通道（`src/views/ReaderView.vue`）**

- 左右热区（各 33% 视口宽，点击翻页）：`onHotzoneClick`（L513-520）按阅读方向映射——LTR 时右热区=下一页，RTL 时左热区=下一页。
- 键盘（L659-725）：左右方向键固定语义（左=上一页、右=下一页，不随 RTL 翻转）；另有空格、上下键、PageUp/Down、Home/End、D/R/F 等快捷键。
- 滚轮（L574-586）：250ms 节流锁（`wheelLock`）防止一次滚动连翻多页；Ctrl/Cmd+滚轮走缩放。
- 底栏按钮与页码滑块（模板 L74-99）。

**4. 渲染管线：缓存优先 + 异步渲染 + 序号作废**

- `watch(currentDisplayPages)` 感知页组变化后触发重渲（L275-327）。
- 每页先查位图缓存（`src/services/pageCache.ts`，LRU 容量 12 张）：命中直接 `blit()` 贴图（约 ≤100ms 上屏）；未命中用 pdf.js 渲染到离屏 canvas，再入缓存并贴图（`paintPage` L430-448）。
- `renderSeq` 渲染序号（L134-135）：快速翻页时旧渲染循环自我中止，迟到的旧页只入缓存不贴图，避免覆盖新页。
- 双页模式两页 `Promise.all` 并行渲染（L454-464）；当前组渲染完成后 `prefetchNeighbors()`（L469-494）异步预取后续 `preloadSpreads` 个页组（设置项，默认 2、范围 0–4）与前一页组。
- pdf.js 渲染层自身对同一 canvas 的重入会取消上一次渲染（`src/services/pdf.ts` L47-60）。

**5. 仿真纸张卷曲动画（`src/services/pageCurl.ts`）**

- 机制（`playPageCurl` L34-199）：翻页前后各截取一张当前画面的合成快照（旧页 `from`、新页 `to`；双页横向拼接，见 `snapshotVisible()` L330-364），在覆盖层 canvas 上以 requestAnimationFrame 逐帧绘制 450ms、easeInOutCubic 的动画，画面元素依次为：底图（新页）→ 翻起块悬空投影 → 旧页保留区 → 翻起块 1:1 原样平移（不镜像、不压缩）→ 翻起块背光暗化 → 折缝根部深影 → 折缝反光 → 自由边高光。
- 关键设计：动画是「覆盖层」，不接管布局与交互；结束时揭除覆盖层，底下显示层已是新页，无缝衔接（文件头注释 L1-3）。
- 触发判定（ReaderView.vue 的 watch，L275-327）：对比前后页组 `firstPage` 是否变化来判定是否真正翻页（模式/方向切换不算）；是则截旧快照 → 渲染新页组 → 截新快照 → `playPageCurl`。方向由 `fromRight = (turnDir === 'forward') === (reader.direction === 'ltr')` 计算（L317）。
- 滑块特例：拖动期间无条件瞬切、不播动画（且尽量只贴缓存图，防堆积无法取消的 pdf.js 渲染任务，L288-301）；松手（change）后播放唯一一次卷曲动画（`finishSlideWithCurl` L554-572）。
- 系统 `prefers-reduced-motion: reduce` 时整个卷曲动画跳过（L148-150、L305）。

### 二、EPUB 翻页

- 核心是 epub.js 的 `rendition`：`store.next()/prev()` 直接调 `rendition.next()/prev()`，由 epub.js 按 CFI 内部切换（`src/stores/epubReader.ts` L219-247）。
- 图片型书（pre-paginated，每 spine section 一页）：`installPaginatedNavigation()`（`src/services/epub.ts` L585-656）给 epub.js 的 manager 打「直通补丁」，完全绕开其依赖容器滚动位置的 next/prev 判定，直接 `clear + updateLayout + append/prepend` 相邻 section；prev 采用「先后页再前页」的 prepend 顺序保证视觉顺序正确；封面场景与书末回退原生逻辑。之所以需要直通，是因为外部布局干预（撑宽、清 margin）会污染容器 scrollWidth，导致原生 next/prev 判定失效（「上一页有效、下一页失效」），根因链见 `specs/EPUB阅读支持问题与解决方案.md` §八。
- 文字型书（reflowable）：走 epub.js 原生分页（同一 section 内分页/双列）。
- 输入：热区（`EpubReaderView.vue` L296-299，右=下一页，不随方向翻转——与 PDF 热区行为不同）；键盘映射与滚轮节流与 PDF 一致（L361-375、L402-464）；滑块拖动节流 200ms 调 `goTo`（L337-359），pre-paginated 按 spine href 定位、reflowable 按 CFI（`epubReader.ts` L249-262、`epub.ts` L688-697）。
- 与 PDF 不同：EPUB 没有卷曲动画，翻页由 epub.js 直接重建 iframe 视图；另有渲染队列韧性补丁 `hardenRenditionQueue()`（`epub.ts` L361-370），防止单次渲染失败导致队列永久停摆、翻页静默失效。
- 进度：epub.js `relocated` 事件驱动当前位置更新（`epubReader.ts` L58-62），防抖 1s 落盘 CFI/百分比（L322-339）。

### 三、两者共同模式

- 都是「翻页 = 修改当前页状态（页组索引 / CFI）→ 响应式触发重渲染 → 防抖落盘进度」的结构。
- 输入通道高度一致：热区、键盘、滚轮节流、滑块、底栏按钮。

## 相关代码

- `src/views/ReaderView.vue`（L2-3、L275-327、L513-586、L659-725）：PDF 阅读器视图；格式分发、翻页动画触发与快照、热区/滚轮/键盘/滑块输入。
- `src/services/pageCurl.ts`（L34-199）：仿真卷曲动画覆盖层逐帧绘制。
- `src/services/spread.ts`（L27-79）：页组划分、方向映射、模式切换重定位。
- `src/stores/reader.ts`（L77-110）：next/prev/goTo、进度防抖保存与 flush。
- `src/services/pageCache.ts`（L5-42）：页面位图 LRU 缓存。
- `src/services/pdf.ts`（L47-97）：pdf.js 按页渲染、同 canvas 重入取消。
- `src/views/EpubReaderView.vue`（L296-299、L337-375、L402-464）：EPUB 热区/滑块/滚轮/键盘输入。
- `src/stores/epubReader.ts`（L219-262、L322-339）：EPUB next/prev/goTo、进度保存。
- `src/services/epub.ts`（L585-656）：pre-paginated 翻页直通补丁；L361-370 渲染队列韧性补丁；L688-697 CFI 跳页。
- `specs/EPUB阅读支持问题与解决方案.md`（§八）：EPUB 翻页无反应问题的根因链与直通补丁的由来。
