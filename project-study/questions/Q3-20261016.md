# Q3-20261016 合集页面漫画卡片展示时的间隔设计

## 问题

合集页面漫画卡片展示时的间隔设计

## 回答

合集页面（`activeCollection` 非空时的合集视图）的卡片间隔由「网格级」与「卡片内部」两层构成，定义在 `LibraryView.vue` 与卡片组件两个文件中；且合集页与主页共用同一个 `.book-grid` 网格样式，卡片间隔完全一致。

### 一、合集页面的结构（间隔的作用位置）

合集视图为左右两栏（`LibraryView.vue` L64-116）：

- 左栏 `.collection-main`（`flex: 1; min-width: 0`，L574-580）：集内书（名称升序）以 `.book-grid` 网格渲染 `BookCard`
- 右栏 `.collection-side`（固定 260px）："继续阅读"侧栏

网格上下还有页头（`.collection-head`）与工具行（`.collection-toolbar`），三者的水平内边距均为 40px（L769、L817、L892），即网格左边线与页头/工具行左边线对齐，形成统一的垂直对齐线。

### 二、卡片与卡片之间：网格 gap 20px

`LibraryView.vue` L886-899：

- `gap: 20px`：行、列间隔统一 20px，是卡片与卡片间距的唯一来源（卡片自身无 margin）
- `grid-template-columns: repeat(auto-fill, minmax(160px, 1fr))`：列宽最小 160px，空间富余时等分拉伸；列数随窗口宽度自动变化
- `padding: 24px 40px`：网格四周留白——上下 24px，左右 40px
- `align-items: start`：卡片按自身内容高度排列，避免同行等高拉伸；注释明确意图是“避免同行等高拉伸出底部空白”
- `align-content: start`（20261016 追加修复）：行轨道只占内容高度、从容器顶部紧密排列。缺省值 `stretch` 会把容器多余高度均摊给每条行轨道——`flex: 1` 让 `.book-grid` 被撑满视口剩余高度（全屏时尤甚），书少行不满时每行被拉长、卡片又因 `align-items: start` 停在行顶，空白全部落到卡片下方，视觉上就是“全屏时每行间距巨大”
- `flex: 1; overflow-y: auto`：网格占满视口剩余高度并自我滚动

空合集提示 `.empty-inline`（L912-919）用 `grid-column: 1 / -1` 横跨整行并 `padding: 48px 0`，不参与卡片排列。

### 三、卡片内部：padding 8 + gap 6

`BookCard.vue` L74-105：

- `.book-card`：`display: flex; flex-direction: column; gap: 6px; padding: 8px`
  - `gap: 6px`：封面与标题之间 6px
  - `padding: 8px`：卡片内边距，封面/标题距卡片边框 8px
  - `border: 1px solid var(--border); border-radius: 10px`
- `.cover`：`aspect-ratio: 3 / 4`——卡片高度由封面（列宽扣掉 2×8px padding 与 2×1px border 后按 3:4 折算）+ 6px gap + 单行标题高度决定
- `.title`：13px，单行省略号（L134-139）

### 四、合集卡与书卡"同构"保证混排节奏一致

主页/合集页会混排 `CollectionCard` 与 `BookCard`，两者刻意做成同构：

- `CollectionCard.vue` L34-47 注释："与 BookCard 完全同构：padding 8 + 3:4 封面 + 单行标题，尺寸一致"；样式实测完全一致（`gap: 6px; padding: 8px; border-radius: 10px`，封面同为 `aspect-ratio: 3 / 4`）
- 合集卡把数量信息做成封面内角标（`.count-badge`，L113-123）而非独立 meta 行（模板注释 L10 说明"保证与书卡片同构等高"）

### 五、右栏与网格之间：不用 gap，用固定宽 + 分隔线

- `.collection-body` 为 flex 行（L568-572）：左 `.collection-main` 占剩余宽度，右 `.collection-side` 固定 `width: 260px; flex-shrink: 0; padding: 20px 24px; border-left: 1px solid var(--border)`（L582-591）——两栏靠 `border-left` 分隔而非 gap
- 窄屏（`max-width: 860px`）侧栏直接 `display: none`（L757-762），网格独占整个宽度
- 合集视图下 `.book-grid` 嵌在 `.collection-main` 内，需逐层传递 flex 高度链（`flex: 1 + min-height: 0`），否则网格的 `flex: 1` 失去参照而坍缩（L564-567 注释）

### 事实与推断

- 事实：上述所有数值、选择器与注释均来自当前代码。
- 推断（由代码结构引申）：合集页与主页共用同一个 `.book-grid` 类（同文件 L66 与 L119 两处使用），二者无法分别调整卡片间隔——任何对 `gap`/`padding` 的修改会同时作用于主页与合集页；合集页与主页的差异只体现在两侧环境（合集页多出右侧栏），而非间隔本身。
