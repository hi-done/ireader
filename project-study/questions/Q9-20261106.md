# Q9-20261106 主页漫画搜索框的尺寸参数在哪里定义

## 问题

主页（文库首页）的漫画搜索框，它的尺寸（宽高、字号、内边距、圆角）分别定义在哪些位置？

## 回答

### 结论

主页搜索框没有一处「集中的尺寸定义」，它的最终尺寸由**三层样式叠出来**：

| 层 | 内容 | 文件位置 |
| --- | --- | --- |
| 结构层 | `<div class="toolbar">` 内的 `input.search-input`，`v-model="library.keyword"` | `src/views/LibraryView.vue:42-48` |
| 全局控件层（高度/字号/内边距/圆角/边框） | `input, select { font-size: 13.5px; padding: 7px 10px; border: 1px solid var(--border); border-radius: var(--radius) }` | `src/style.css:367-377`（`--radius: 8px` 定义在 `src/style.css:53`） |
| 页面局部层（宽度） | `.search-input { flex: 1; max-width: 420px }` | `src/views/LibraryView.vue:805-808` |
| 容器层（四周留白、元素间距） | `.toolbar { display:flex; align-items:center; gap:16px; padding:14px 40px }` | `src/views/LibraryView.vue:795-803` |

所以要调整：

- **改宽度** → `LibraryView.vue:805-808` 的 `max-width: 420px`（`flex: 1` 决定它在工具栏剩余空间里伸缩，右侧 `toolbar-group` 有 `margin-left: auto` 占住右端，见 L810-815）。
- **改高度/字号/内边距/圆角** → `src/style.css:367-377` 的 `input, select` 规则。注意这是**全局**规则，同时作用于设置页、批量管理页、各类对话框的输入框与下拉框；只想改主页搜索框时，应在 `LibraryView.vue` 的 `.search-input` 里局部覆盖（该 `<style scoped>` 起始于 L605）。
- **改位置/上下留白** → `LibraryView.vue:795-803` 的 `.toolbar`（`padding: 14px 40px`、`gap: 16px`）。

### 需要在意的三个细节

1. **本项目没有全局 `box-sizing: border-box` 重置**：`src/style.css` 中零匹配 `box-sizing`，只有各组件按需局部声明（如 `BookCard.vue:312`、`SelectMenu.vue:350`）。而 `.search-input` 没有声明，走默认的 `content-box`，因此 `max-width: 420px` 约束的是**内容盒**，实际渲染宽度约为 `420 + 10*2(padding) + 1*2(border) ≈ 442px`。（宽度这部分是推断，基于 CSS 盒模型；`box-sizing` 缺失是代码事实。）
2. **高度没有显式声明**：由 `font-size: 13.5px` 的行盒高度 + `padding: 7px` + `border: 1px` 自然撑出，量级约 32px（推断值，未在代码中写死）。
3. **聚焦态只改视觉不改布局**：`src/style.css:384-389` 的 `input:focus` 加了 `box-shadow: 0 0 0 3px var(--brand-soft)`，因为用 box-shadow 而非 outline/border 加宽，聚焦时不会引起工具栏回流。

### 容易踩的坑：同名类有两份，各在各的 scoped 里

项目里 `.search-input` 出现在两个不同的视图，尺寸**互不影响**：

- `src/views/LibraryView.vue:805-808`：`flex: 1; max-width: 420px` —— 本条问题所指的主页搜索框。
- `src/views/LibraryManageView.vue:352-355`：`flex: 1; max-width: 320px` —— 「漫画批量管理」页的搜索框（`LibraryManageView.vue:46-51`），右边界更窄。

两者都只覆盖宽度，高度/字号/圆角仍来自 `src/style.css:367-377` 那条全局 `input, select` 规则。另外 `src/views/LibraryView.vue:746-750` 的 `@media (max-width: 860px)` 只隐藏合集侧栏（`.collection-side`），**不会**改搜索框尺寸。

### placeholder 与文案

占位文案不走样式，来自 i18n 键 `library.search.placeholder`（`src/i18n/locales/zh-CN.ts:70` 等），颜色由 `src/style.css:391-393` 的 `input::placeholder { color: var(--text-muted) }` 决定。
