# 图书卡片交互与图标苹果风美化设计方案

> 状态：设计稿（v1.2.6 已实现）
> 目标版本：v1.2.6（沿用当前 package.json 版本，本次不改版本号、不打 tag，由用户自行发版时确定）
> 范围：文库主页与合集视图网格中的 `BookCard` / `CollectionCard`——卡片壳材质与圆角、3D 倾斜跟随交互、三个操作按钮的图标与毛玻璃圆钮、进度环 / 缺失徽章 / 无封面占位
> 实现约束：遵循 `ireader-dev-tasks`（任务 D：渲染层组件归属与主题兼容；任务 F：验证流程）与 `ireader-code-conventions`（中文注释、纯逻辑入 `src/services/` 并补 Vitest、不新增依赖、颜色一律取 CSS 变量）

## 一、需求拆解与验收标准

| # | 原始需求 | 设计落点 | 验收方式 |
|---|----------|----------|----------|
| 1 | 卡片交互效果更符合苹果风格 | 指针在卡片内移动时整卡 3D 倾斜（上限 6°）+ 封面跟随高光；离开 450ms 缓出回正；按下倾角减半并 `scale(0.98)`（§四） | 主页网格内移动指针，卡片随位置连续倾斜、高光同步移动；移出后平滑回正无跳变；按下有回弹感 |
| 2 | 卡片上的图标美化 | 三个操作按钮由「文件夹 SVG + 字符 ✎ / ×」统一为 SF Symbols 风格内联描边 SVG（folder / pencil / xmark，1.5px 圆头、`currentColor`），按钮改 26px 毛玻璃圆钮（§6.2 / §6.3） | 三个圆钮图标粗细、圆角、光学尺寸一致；hover 提亮、移除钮 hover 变危险色；深浅主题下材质成立 |
| 3 | 图标可发现性与操作可达性 | 操作按钮由 `display: none → flex` 改为 `opacity / translateY` 淡入，并在 `:focus-within` 时同样显示 | hover 时按钮自上方淡入（0/20/40ms 错峰）；键盘 Tab 进入按钮时按钮组自动显示、焦点环可见（现有 `display:none` 使按钮键盘不可达） |
| 4 | 封面浮层信息同样苹果化 | 进度环改毛玻璃圆底 + 细环 + `tabular-nums` 数字；「文件缺失」改毛玻璃胶囊 + 黄色警告图标；无封面占位改「描边书页图标 + 文案」 | 深浅封面底色下进度数字与徽章文字均可读；缺失卡片点击仍弹 `MissingFileDialog` |
| 5 | 合集卡片与书卡片观感一致 | 抽全局 `.tilt-card` 卡壳承载两卡共用的圆角 / 阴影 / 倾斜 / 按压；`CollectionCard` 数量徽章改用同一毛玻璃徽章材质 | 主页网格中两类卡片并排：hover 倾斜角度、阴影、按压手感完全一致 |
| 6 | 不改变业务行为 | 点击打开、`open/remove/rename/move` 四个 emit、进度百分比口径、`missing` 拦截逻辑全部不动 | 逐项回归：打开阅读器、移入合集、重命名、移除、缺失重定位、合集进入/返回 |

**核心验收口径**：浅色与深色主题下，文库网格中 `BookCard` / `CollectionCard` 在指针移入后 1 帧内开始倾斜、倾角不超过 6°、高光中心与指针位置同步，移出后 450ms 内回到 0°；三个操作按钮与两处徽章材质统一为「深色半透明 + 模糊 + 1px 半透明白描边」；键盘 Tab 能连续触达三个按钮并触发；`npm run typecheck`、`npm test` 通过，阅读页 / 设置页 / 统计页视觉零变化。

## 二、非目标（本期不做）

- 不引入图标库或动画库（lucide、@iconify、GSAP 等）：纯离线红线 + 「不新增依赖」约束，图标一律内联 SVG。
- 不做卡片入场 stagger 动画：文库每次 `library:changed` 与封面回填都会重排重播，高频干扰；统计页 `cardIn` 的一次性入场模式不适用于常驻网格。
- 不做封面 hover 放大（zoom）：与 3D 倾斜叠加会产生「双层缩放」的廉价感，倾斜 + 阴影提升已足够表达高度。
- 不做点击涟漪 / 反光扫过（shine sweep）/ 粒子等非苹果材质效果。
- 不改卡片 DOM 语义：根元素仍是 `div @click`，不新增 `role` / `tabindex`（`role="button"` 内嵌三个 `<button>` 会造成语义冲突）；键盘可达性只修「按钮因 `display:none` 不可聚焦」这一 CSS 缺陷，不新增「Tab 聚焦整卡后 Enter 打开」。
- 不改「继续阅读」右侧 3D 立体书、`CollectionPickerDialog` / `AddBooksDialog` 内的书目列表、设置页 / 统计页 / 阅读页任何控件。
- 不改 `LibraryView.vue`：网格列宽（`minmax(160px, 1fr)`）、间距（20px）、内边距（24px 40px）与 `align-items / align-content: start` 均不动。
- 不改进度百分比计算口径（EPUB `percentage` / PDF 按页折算）、`missing` 判定与任何 emit 时序。
- 不改全局按钮三级体系、`--shadow-sm` / `--shadow-md` / `--menu-shadow` 既有取值，只新增卡片专用令牌。

### 3.2 关键决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 改动范围（用户确认） | `BookCard` 全面改造 + `CollectionCard` 同步卡壳与徽章 | 两类卡片同网格并排；只改一类会出现同屏两种 hover 手感与圆角 |
| 交互强度（用户确认） | 3D 倾斜跟随指针（Apple TV 海报风）+ 阴影提升 + 按下回弹 | 用户明确选择；相较 iOS 轻量上浮，倾斜对指针位置有连续反馈，更「有生命感」 |
| 图标方案（用户确认） | SF Symbols 风格 1.5px 圆头描边内联 SVG + 26px 毛玻璃圆钮，hover / focus-within 淡入 | 现有 `✎` / `×` 为文字字符，形态随字体与字号漂移；描边 SVG 与 `SelectMenu` 的双箭头图标语言一致 |
| 倾斜角度上限 | 6°，线性映射、无死区 | 160px 卡宽、约 230px 卡高时边缘位移约 12px，已足够明显；10° 会让 13px 标题明显发虚 |
| 倾斜基准矩形 | `pointerenter` 时缓存，仅在宽高变化 >1px 时重测 | 每帧 `getBoundingClientRect()` 会读到被自身 `rotate` 改变后的矩形，形成「倾斜改变基准 → 角度再变」的抖动反馈 |
| 高光实现 | 独立 `.cover-glare` 覆盖层 + `radial-gradient`（中心走 CSS 变量） | 不改封面图本身，不依赖 `mix-blend-mode`；`overflow: hidden` 的封面天然裁出圆角 |
| 卡壳与倾斜样式归属 | 上收全局 `.tilt-card`，组件 scoped 只留内容布局 | `CollectionCard` 注释已写「与 BookCard 完全同构」，两份 15 行重复样式必然分叉；与项目「重复页头样式上收全局」的既有决策一致 |
| 徽章材质归属 | 上收全局 `.cover-badge`（只含材质，定位留在组件） | 缺失徽章（左上）与数量徽章（左下）定位不同但材质完全一致，一处改全站生效 |
| 圆角 | 卡片 10px → `--card-radius: 12px`，封面 4px → `--card-cover-radius: 8px` | 现有 10/4 的封面圆角过小，与 26px 圆钮、毛玻璃徽章放在一起比例失衡；12/8 更接近 iOS 卡片与缩略图比例 |
| hover 边框 | 移除现有 `border-color: var(--text-muted)` 加深 | 12px 圆角 + 阴影提升后，再加深边框会显得「框住」；苹果卡片靠阴影表达层级 |
| 按钮显示方式 | `opacity + translateY` 淡入（0/20/40ms 错峰），`display` 常驻 | `display: none` 的元素不可聚焦，键盘用户无法触达移入/重命名/移除；改为不透明即可同时解决可达性与无过渡突变 |
| 减弱动效 / 触屏 | 不挂载指针监听 | 与 `StatCard` / `ReaderView` / `SelectMenu` 现有「一次性判定 `prefers-reduced-motion`」写法一致；触屏无 hover 语义 |
| 纯逻辑归属 | `computeCardTilt` 抽 `src/services/cardTilt.ts` 并补单测 | 项目约定纯逻辑入 services、Vitest 只测纯逻辑；倾斜映射可完全脱离 DOM 验证（`coverQueue.ts` 同为「DOM 副作用 + 可测纯函数」同文件先例） |

## 四、核心算法与交互口径

### 4.1 倾斜映射

```ts
// src/services/cardTilt.ts
export interface CardTiltRect {
  left: number
  top: number
  width: number
  height: number
}

export interface CardTiltInput extends CardTiltRect {
  clientX: number
  clientY: number
}

export interface CardTilt {
  /** 绕 X 轴旋转角（deg）：指针在卡片上半部为正（卡片上仰） */
  rotateX: number
  /** 绕 Y 轴旋转角（deg）：指针在卡片右半部为正（右侧后仰） */
  rotateY: number
  /** 高光中心横坐标（百分比 0~100） */
  glareX: number
  /** 高光中心纵坐标（百分比 0~100） */
  glareY: number
  /** 指针是否仍在卡片矩形内（越界坐标会被钳制到边缘） */
  inside: boolean
}

/** 指针位置 → 倾角与高光中心；maxDeg 默认 6，宽高非法时返回零值 */
export function computeCardTilt(input: CardTiltInput, maxDeg = 6): CardTilt
```

实现口径：

```ts
if (width <= 0 || height <= 0) {
  return { rotateX: 0, rotateY: 0, glareX: 50, glareY: 50, inside: false }
}
const rawX = (clientX - left) / width
const rawY = (clientY - top) / height
const inside = rawX >= 0 && rawX <= 1 && rawY >= 0 && rawY <= 1
const ratioX = clamp01(rawX)
const ratioY = clamp01(rawY)
return {
  rotateY: (ratioX * 2 - 1) * maxDeg,   // 右侧为正
  rotateX: (1 - ratioY * 2) * maxDeg,   // 上方为正（上仰）
  glareX: ratioX * 100,
  glareY: ratioY * 100,
  inside,
}
```

- `clamp01(v) = Math.min(1, Math.max(0, v))`，模块内私有。
- 角度与高光同源：高光中心恒等于指针在卡片内的相对位置，倾斜方向与高光偏移天然一致。
- 不使用缓动曲线平滑角度：角度是位置的线性函数，平滑交给 CSS `transition`（跟手 80ms），避免算法层再引入滞后。

### 4.2 指针生命周期与 DOM 接线

```ts
export interface CardTiltOptions {
  /** 最大倾角（deg），默认 6 */
  maxDeg?: number
}

export interface CardTiltHandle {
  /** 移除全部监听并取消未执行的 rAF；幂等 */
  detach(): void
}

/** 挂载倾斜跟随；减弱动效或非精细指针设备时返回空句柄 */
export function attachCardTilt(el: HTMLElement, options?: CardTiltOptions): CardTiltHandle
```

状态机：

| 时机 | 行为 |
|------|------|
| `attachCardTilt` | `prefers-reduced-motion: reduce` 命中，或 `(hover: hover) and (pointer: fine)` 不满足 → 直接返回空句柄，不注册任何监听 |
| `pointerenter` | `pointerType === 'touch'` 忽略；否则测量并缓存基准矩形，加 `is-tilting` class（切换为跟手过渡） |
| `pointermove` | 记录 `clientX / clientY`；缓存宽高变化 >1px 时重测基准；用 rAF 合帧（同一帧多次移动只写一次） |
| rAF 回调 | `computeCardTilt` → `inside === false` 时跳过写入；否则写 `--tilt-x` / `--tilt-y` / `--glare-x` / `--glare-y` 四个内联变量 |
| `pointerleave` / `pointercancel` | 取消未执行的 rAF、移除 `is-tilting`、移除四个内联变量（回落到样式表默认值，CSS 450ms 缓出回正） |
| `window blur` | 同 `pointerleave`（切走应用时复位，避免回来时卡片保持倾斜） |
| `detach` | 移除上述全部监听 + 取消 rAF；幂等 |

实现要点：

1. 监听只挂在卡片根元素上：`pointerenter` / `pointerleave` 不冒泡，卡片内圆钮悬停不会重复触发；`pointermove` 冒泡到根，按钮上移动时整卡继续倾斜。
2. 写变量用 `el.style.setProperty('--tilt-x', `${deg.toFixed(2)}deg`)`，全程不触碰 Vue 响应式状态，不触发组件重渲染。
3. `will-change: transform` 只写在 `.is-tilting` 上：N 张卡片常驻 `will-change` 会创建 N 个合成层，显存与滚动性能都不划算。
4. 组件侧只保留三行接线（`onMounted` / `onBeforeUnmount`），两卡片完全一致：

```ts
const cardEl = ref<HTMLElement | null>(null)
let tilt: CardTiltHandle | null = null
onMounted(() => {
  if (cardEl.value) tilt = attachCardTilt(cardEl.value)
})
onBeforeUnmount(() => {
  tilt?.detach()
  tilt = null
})
```

### 4.3 CSS 变换合成与过渡

```css
/* 静止：变量默认值写在样式表，内联变量被移除后自动回落 */
.tilt-card {
  --tilt-x: 0deg;
  --tilt-y: 0deg;
  --glare-x: 50%;
  --glare-y: 50%;
  transform: perspective(900px) rotateX(var(--tilt-x)) rotateY(var(--tilt-y));
  transition:
    transform 0.45s cubic-bezier(0.22, 0.8, 0.24, 1),
    box-shadow 0.25s ease;
}

/* 跟手：80ms 线性，指针移动时几乎无滞后 */
.tilt-card.is-tilting {
  transition:
    transform 0.08s linear,
    box-shadow 0.25s ease;
  will-change: transform;
}

.tilt-card:hover {
  box-shadow: var(--card-shadow-lift);
  z-index: 1; /* 倾斜的卡片压在相邻卡片之上（grid 子项，需 position: relative） */
}

/* 按压：倾角减半 + 缩到 98%，松开回弹到 hover 态 */
.tilt-card:active {
  transform:
    perspective(900px)
    rotateX(calc(var(--tilt-x) * 0.5))
    rotateY(calc(var(--tilt-y) * 0.5))
    scale(0.98);
}
```

- 不加 `translateY(-2px)`：与 rotate 叠加后卡片「抬起方向」会随倾角变化，反而不自然；高度由阴影表达。
- 不设 `transform-style: preserve-3d`：卡片内没有需要独立 3D 变换的图层，`preserve-3d` 会与按钮上的 `backdrop-filter` 组合出不必要的合成开销。
- `perspective()` 写在自身 `transform` 里（而非父级 `.book-grid` 的 `perspective` 属性）：只影响本卡片，不影响网格其他元素，也避免给整个网格创建 3D 上下文。

### 4.4 边界场景防护

| 场景 | 处理 |
|------|------|
| 卡片宽或高为 0（隐藏 / 尚未布局） | `computeCardTilt` 返回全零 + 高光居中；控制器因 `inside === false` 不写变量 |
| 指针快速越界（`pointermove` 坐标已在卡片外） | 坐标钳制到边缘，`inside === false` 时跳过写入；由 `pointerleave` 统一复位 |
| 触屏 / 手写笔输入 | `pointerType === 'touch'` 直接忽略；媒体查询 `(hover: hover) and (pointer: fine)` 不满足时整卡不挂载 |
| 系统开启「减弱动态效果」 | 挂载时判定一次即跳过监听，卡片仅有阴影过渡 |
| 窗口缩放 / 布局变化 | `pointermove` 中比较缓存宽高，差异 >1px 时重测基准矩形 |
| 窗口失焦 / 切换到其他应用 | `window blur` 复位并移除内联变量 |
| 卡片被 `v-for` 卸载 | `onBeforeUnmount` → `detach()`：移除监听、取消 rAF、移除内联变量 |
| 鼠标停在卡片内不动、页面滚动 | 不产生 `pointermove`，角度不变；指针离开或 blur 时复位 |
| 快速连续移动 | rAF 合帧，每帧最多 4 次 `setProperty`，不触发 Vue 渲染 |
| 在圆钮上点击 | 祖先 `:active` 同样命中，卡片轻微缩小（预期手感）；`@click.stop` 保证不触发打开 |

8. 合集卡片：hover 倾斜与书卡一致；数量徽章材质一致；进入合集后网格内书卡同样可用。
9. 进度环：有进度的书显示环 + 数字；hover 时 180ms 淡出、按钮出现；移出后恢复。
10. 深浅主题各跑一遍 1~9：卡壳、按钮、徽章、高光在两种主题下均成立（深色下阴影加重、描边清晰）。
11. 系统开启「减弱动态效果」：卡片无倾斜与缩放，按钮淡入仍在；重新打开应用生效（一次性判定）。
12. 性能：导入 100 本以上，滚动网格流畅；连续 hover / 移出 30 次后切换页面再返回，无残留监听（内存不持续增长）。
13. 回归：搜索、排序、升降序、合集新建 / 解散、从主页添加、缺失重定位、封面生成进度条均不受影响。

## 十、风险与取舍记录

| 项 | 取舍 | 影响与备注 |
|----|------|------------|
| 3D 倾斜与文字清晰度 | 上限 6°，且只在精细指针设备启用 | 13px 标题在倾斜时有轻微亚像素模糊；若视觉验收觉得糊，把 `maxDeg` 降到 4 即可（单点参数），扩展点已留 |
| 倾斜基准抖动 | `pointerenter` 缓存矩形，仅尺寸变化时重测 | 滚动中指针仍停在卡片上时，基准可能短暂偏差；指针移动或离开即修正，不影响常态使用 |
| 每卡监听开销 | 监听只挂在卡片根上，`pointerleave` 后不再计算；rAF 合帧 | 100 张卡片同时只有一张处于倾斜计算，开销可忽略 |
| `will-change` 常驻 | 只在 `.is-tilting` 上声明 | 避免 N 个常驻合成层占用显存与拖慢滚动 |
| 全局 `button:hover` 特异性 | 本地悬停规则统一带 `:not(:disabled)` | 否则圆钮 hover 被刷成 `--surface-2` 浅灰；与项目既有写法一致，后续新按钮沿用同规则 |
| 按钮组 `pointer-events: none` | 隐藏时不可点、但仍可 Tab 聚焦 | 聚焦后 `:focus-within` 立即显示，键盘路径可用；不做 `visibility: hidden`（同样会失去焦点可达性） |
| 倾斜 + `backdrop-filter` | 按钮与徽章在倾斜容器内使用 `backdrop-filter` | Chromium 下采样区随变换轻微偏移，视觉无感；若低端机掉帧，优先去掉 `.cover-glare` 的混合层而不是按钮材质 |
| 圆角变更 | 卡片 10 → 12、封面 4 → 8 | 网格尺寸与封面比例不变，仅四角裁切区域略增；与统计页面板 14px、按钮 8px 形成 12/14/8 的层级，不再出现「10 与 14 无规律」的观感 |
| 缺失徽章去红色 | 红色语义改由黄色警告图标承担，底色统一毛玻璃 | 与数量徽章材质统一；若后续需要强调破坏性，可在图标色上改用 `--danger`（单点改动） |
| 触屏无按钮组 | 与改造前一致（原本也依赖 hover） | 本期不引入「常驻按钮」模式；若未来上触屏设备，可作为 `(hover: none)` 媒体查询分支扩展 |
| 卡片 DOM 语义 | 不新增 `role` / `tabindex` | 避免 `role="button"` 内嵌三个按钮的无障碍冲突；键盘打开整卡留作后续独立评估 |
| 键盘可达性的行为变化 | `display: none → opacity` 后按钮进入 Tab 序列 | 这是修复而非回退：改造前按钮键盘完全不可达；冒烟第 5 条覆盖 |
