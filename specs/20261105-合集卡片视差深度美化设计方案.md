## 一、需求拆解与验收标准

| # | 原始需求 | 设计落点 | 验收方式 |
|---|----------|----------|----------|
| 1 | 参考 Parallax Depth Cards，加入「深度」 | 倾角 10°（demo 为 ±15°，实机验收后下调）+ 视距按 demo 比例缩到 560px；封面媒体层反向视差（横 8.33% / 纵 6.25%，比例同 demo 的 ±20px）；卡框 / 徽章 / 书名行保持静止层（§4.2） | 指针从卡片中心移到边缘，画面相对卡框连续偏移 0 → ≈17px；卡片倾角到 10°；1px 描边、徽章、书名行零位移 |

**核心验收口径**：160px 以上列宽下，合集卡与书卡外框上沿、下沿齐平（误差 <1px），封面铺满整卡、无纸页缘残留；hover 时卡片倾到 10°、封面画面反向偏移 ≈17px 并在移出后 0.45s 回正，1px 描边、数量徽章与底部书名（含 CardTip 浮层）全程零位移；封面四角不露底、不越出卡壳描边；深浅主题与「减弱动态效果」下均无异常；`npm run typecheck`、`npm test` 通过，`BookCard` 与其余页面视觉零变化。

## 二、非目标（本期不做）

- **不改书卡**（仅合集卡）：`BookCard.vue` 模板与样式一行不动，书卡仍是 6° 倾角 + 900px 视距。
- **不做纸页缘**（v2 删除）：卡壳 `padding: 8px` 的「一叠书」几何废弃，第三层页缘等取舍一并作废。
- **不在卡内新增 hover 文本**（已确认）：`.card-title-row` 只有已有书名，不新增正文；11~12px 文字在 3D 层内发虚是提示框改 Teleport 浮层的既有结论（`20261021-图书卡片提示框苹果风美化设计方案.md` v2）。
- **不引入 `transform-style: preserve-3d` / `translateZ`**：既有决策明确不加（与徽章 `backdrop-filter` 组合出多余合成开销）；本期视差为屏幕空间 2D 位移。
- **不加封面 zoom、不加 `filter: brightness()`**：前者与 3D 倾斜叠加成「双层缩放」（既有决策）；后者会让封面层反复重栅格化。hover 亮度反馈交给既有 `.cover-glare`。
- **不加白色外发光边**：demo 的白色外环在浅色主题不可见、深色主题偏电玩感；浮起只靠投影加深。
- 不改 `--card-radius` / `--card-cover-radius` / 网格列宽与间距、`CardTip` 定位逻辑、`coverBook` 排序口径、`tp('common.bookCount')` 文案。
- 不新增 npm 依赖（纯 CSS + 既有 `cardTilt.ts`）。

## 三、总体设计

### 3.1 结构与分层

```
LibraryView.vue（.book-grid：minmax(160px,1fr) / gap 20px / padding 24px 40px / align-items:start）
  └─ CollectionCard.vue        ← 本期唯一改动组件
       ├─ 根 .collection-card.tilt-card（全局卡壳 + 内联 --tilt-*，本期覆盖 gap:0 / 视距 560px）
       │    ├─ ::before        占位：aspect-ratio 3/4 + margin-bottom:-10px —— 决定卡高（§4.5）
       │    ├─ .cover          绝对定位 inset:0 = 铺满整卡（圆角对齐卡壳内沿）
       │    │    ├─ .cover-media  视差层：translate3d(--par-x * -8.333%, --par-y * -6.25%)
       │    │    │    └─ img | .cover-placeholder（占位不参与视差）
       │    │    ├─ .cover-scrim  静止：底部 52% 常驻纱罩（书名底衬）
       │    │    ├─ .cover-glare  既有：指针径向高光
       │    │    ├─ .count-badge  静止：数量徽章（左上 8px）
       │    │    └─ ::after       hover 渐显 1px 发丝内框
       │    ├─ .card-title-row 在流内占位（高度与书卡同名行一致）+ z-index:1 压到封面底部
       │    └─ <CardTip>       零改动
       └─ attachCardTilt(cardEl, { maxDeg: 10 })
            写 --tilt-x / --tilt-y / --glare-x / --glare-y（既有）与 --par-x / --par-y（§4.1）
```

**分层铁律**：视差只作用于「封面画面」这一纯装饰层。文字、徽章、卡框、提示框全部落在静止层——这是「既不抖、也不发虚」的唯一保证。

### 3.2 demo 手法映射

| `demos/Parallax Depth Cards` 手法 | 本项目取舍 |
|---|---|
| `.card-wrap` `perspective(800px)` + 卡片 `rotateX/Y` 到 ±15°（`mousePX * 30`） | 倾角取 10°（demo 为 15°，实机验收后下调，保 13px 书名锐度）；视距按卡宽比例换算 800×(168/240)≈560px，否则小卡上大倾角的透视收缩不足、看着仍「浅」 |
| `.card-bg` 反向平移 ±20px（`mousePX * -40`，卡 240×320）+ `top/left:-20px` 预放大兜边 | 换算成比例：横 8.333%、纵 6.25%（与 demo 同一相对幅度）；外套 `inset:-18px` 兜住 ±17px 位移 |
| 图片铺满整卡、信息叠在图上 | v2 采用：卡壳无内边距，封面即卡面，书名与数量叠在封面之上 |
| hover 内衬 5~6px 黑白双环（相框） | 封面内侧 1px 白色发丝框（`inset:1px`，圆角 = 卡壳内沿 −1px）；不做 5~6px 相框（会与书名 / 徽章交错） |
| `.card-info` 底部渐变 + 白色大标题常驻压在图上 | 底部 52% 常驻纱罩 + 13px 白字书名（字号按 160px 网格收敛，不做 36px 海报字） |
| `.card-info` 正文 hover 上滑渐显 | 不做：3D 层内小字发虚（§二） |
| `.card-bg` 透明度 0.5 → 0.8（压暗保文字） | 不做：封面是内容主体，压暗交给底部纱罩，整图亮度不变 |
| hover 阴影叠加白色外发光 | 仅投影升级 `--card-shadow-lift-strong`，不加白边（§二） |
| 卡片 240×320 固定尺寸 | 改为跟随网格列宽：卡高由书卡同构公式反推（§4.5），保证同屏尺寸一致 |

### 3.3 关键决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 改造范围（用户确认） | 仅 `CollectionCard` | 需求指向合集卡；书卡是验收过的稳定形态，一并改动会把回归面扩大到按钮组 / 进度环 / 缺失徽章 |
| 深度力度（用户确认，v3 初版 / v4 微调） | 倾角 10° + 视距 560px + 画面反向视差 8.33%/6.25% | 首版按 demo 原值取 15°，实机验收后用户要求降到 10°：倾角减半仍明显深于书卡（6°），且 13px 书名在重采样下更耐看；视差与视距保持 demo 比例，所以「深」的感受不靠倾角硬撑 |
| 卡内悬停文本（用户确认） | 不加正文，仅有既有书名 + 数量 | 倾斜容器内 11~12px 文字必发虚；信息需求由书名提示框覆盖 |
| 卡面几何（v2 用户确认） | 无内边距 + 封面铺满 + 书名叠底 | 用户要求「封面占据整张合集卡牌」；书名若留在卡外会破坏「封面即卡面」 |
| 尺寸一致（v3 用户确认） | 用 `::before` 占位撑出与书卡封面等高的高度，书名行在流内占位 | 书卡高是「内边距 + 封面 + 间距 + 书名行」的线性组合，合集卡无内边距却要同高 → 必须用同构的流内占位反推，`aspect-ratio` 单值无法表达（含固定像素偏移） |
| 内边距归零后的圆角 | `.cover` 圆角 `calc(var(--card-radius) - 1px)`，封面自带 `overflow: hidden` | 卡壳外半径 12px、描边 1px → 内沿 11px；不用卡壳 `overflow: hidden`，避免给倾斜壳引入额外裁剪层 |
| 书名可读性 | 常驻 52% 底部纱罩（0.68 → 0.4 → 透明）+ 白字 + `text-shadow` | 封面图不可控，浅色封面上纯白字会糊；纱罩常驻才能保证扫描时书名始终可读 |
| 视差数据来源 | 扩展 `computeCardTilt` 返回 `offsetX / offsetY`（-1~1），由 `attachCardTilt` 写 `--par-x / --par-y` | 若从既有 `--glare-x`（百分比）在 CSS 里反推 px，各层元素尺寸不同会导致同一系数对应不同位移；归一化数值 + CSS 侧百分比才能「一处数据、自动随卡宽缩放」 |
| 视差幅度单位 | 百分比（相对媒体层自身尺寸） | demo 是固定 px（卡尺寸固定）；本项目列宽随窗口伸缩，用百分比才能保持同一相对深度 |
| 媒体层预放大 | 外套 `inset: -18px` | 位移需求解不等式：横 8.333%·(W+2I) ≤ I → I ≥ 16.6px，纵 6.25%·(H+2I) ≤ I → I ≥ 17.1px；取 18px 留亚像素余量 |
| 投影加深归属 | 新增 `--card-shadow-lift-strong`，只被 `.collection-card` 消费 | 不动既有 `--card-shadow-lift`，书卡 hover 手感零变化；主题成对定义 |
| 视距变量化 | 新增 `--card-perspective`（默认 900px，合集卡 560px） | 只改常量不改结构；书卡走默认值，`.tilt-card` 仍是唯一倾斜来源 |

## 四、核心算法与交互口径

### 4.1 归一化偏移映射（`src/services/cardTilt.ts`）

在既有返回值上追加两个字段，其余语义不变：

```ts
export interface CardTilt {
  /** 绕 X 轴旋转角（deg）：指针在卡片上半部为正（卡片上仰） */
  rotateX: number
  /** 绕 Y 轴旋转角（deg）：指针在卡片右半部为正（右侧后仰） */
  rotateY: number
  /** 高光中心横坐标（百分比 0~100） */
  glareX: number
  /** 高光中心纵坐标（百分比 0~100） */
  glareY: number
  /** 指针相对卡片中心的归一化横向偏移（-1~1，右为正）；供视差层换算位移 */
  offsetX: number
  /** 指针相对卡片中心的归一化纵向偏移（-1~1，下为正）；供视差层换算位移 */
  offsetY: number
  /** 指针是否仍在卡片矩形内（越界坐标会被钳制到边缘） */
  inside: boolean
}
```

实现口径（与既有倾角严格同源）：

```ts
if (width <= 0 || height <= 0) {
  return { rotateX: 0, rotateY: 0, glareX: 50, glareY: 50, offsetX: 0, offsetY: 0, inside: false }
}
const rawX = (clientX - left) / width
const rawY = (clientY - top) / height
const inside = rawX >= 0 && rawX <= 1 && rawY >= 0 && rawY <= 1
const ratioX = clamp01(rawX)
const ratioY = clamp01(rawY)
const offsetX = ratioX * 2 - 1      // 右为正
const offsetY = ratioY * 2 - 1      // 下为正
return {
  rotateY: offsetX * maxDeg,        // 等价于既有 (ratioX * 2 - 1) * maxDeg
  rotateX: 0 - offsetY * maxDeg,    // 等价于既有 (1 - ratioY * 2) * maxDeg，`0 -` 避免正中算出 -0
  glareX: ratioX * 100,
  glareY: ratioY * 100,
  offsetX,
  offsetY,
  inside,
}
```

`attachCardTilt` 的写入帧追加两项（数值型自定义属性，不带单位，便于 CSS 侧换乘百分比）：

```ts
el.style.setProperty('--par-x', tilt.offsetX.toFixed(3))
el.style.setProperty('--par-y', tilt.offsetY.toFixed(3))
```

`reset()` 一并 `removeProperty('--par-x' / '--par-y')`，回落到样式表默认值 `0`。

- 倾角仍由归一化偏移派生，但 `rotateX` 写作 `0 - offsetY * maxDeg`：直接取负在正中会得到 `-0`（`Object.is(-0, 0)` 为 false），会污染数值断言与内联变量输出。落地时该写法已被单测固定。
- 合集卡 `attachCardTilt(el, { maxDeg: 10 })`；书卡沿用默认 `DEFAULT_MAX_DEG = 6`。倾角上限是 `attachCardTilt` 的入参，不写死在 CSS，因此同一套接线可以两种力度。
- 书卡也会收到 `--par-*`，但其 CSS 不消费，行为与改造前完全一致；单张 hover 卡片每帧多 2 次 `setProperty`，开销可忽略。

### 4.2 分层与视差系数

| 层 | 消费变量 | 横向 | 纵向 | 对应 demo 值 | 设计意图 |
|---|---|---|---|---|---|
| `.cover-media`（封面画面） | `--par-x / --par-y` | `-8.333%` | `-6.25%` | `mousePX * -40px`（240×320 卡 → ±20px） | 反向滞后 → 「透过卡面看进去」的深度；外套 `inset:-18px` 兜住露底 |
| `.cover` / `.cover-scrim` / `.cover-glare` / `.count-badge` / `.card-title-row` / `.cover::after` | — | `0` | `0` | — | 静止层：卡框、纱罩、徽章、文字、提示框零位移 |

```css
.cover-media {
  inset: -18px; /* 预放大 18px ≈ 17px 位移需求 + 余量 */
  transform: translate3d(calc(var(--par-x) * -8.333%), calc(var(--par-y) * -6.25%), 0);
}
```

以 168px 列宽估算：媒体层约 204×278 → 横向位移 ≈17px、纵向 ≈17.4px，与 demo 在同一相对幅度上（demo ±20px / 240 宽 = 8.33%）。

### 4.3 过渡时序

| 状态 | 规则 | 说明 |
|---|---|---|
| 静止 → hover（进入） | `transform 0.45s cubic-bezier(0.22,0.8,0.24,1)` | 与 `.tilt-card` 同曲线；demo 用 0.6s，此处沿用项目既有手感 |
| 指针跟随中（`.is-tilting`） | `.cover-media` 覆盖为 `transform 0.08s linear` + `will-change: transform` | 与既有「跟手 80ms」同拍，避免 450ms 缓出拖影 |
| 离开 | 内联变量被移除 → 回落 `0`，由 0.45s 曲线缓出 | 与卡片回正同步；demo 是延迟 1s 归零，不做（迟滞感重） |
| 发丝内框 | `opacity 0.35s ease` | 纯透明度变化，减弱动效下也可保留 |
| 投影 | `box-shadow 0.25s ease`（沿用 `.tilt-card`） | 只换取值，不加过渡 |

### 4.4 边界场景防护

| 场景 | 处理 |
|---|---|
| 指针到卡片四角（`--par-x = --par-y = ±1`） | 媒体层最大偏移 ≈17px，外套四周各余 18px → 永不露底 |
| 指针越界（快速划过边缘） | `computeCardTilt` 钳制到 ±1 且 `inside=false`，帧不写入；由 `pointerleave` 复位 |
| 触屏 / 手写笔 | `attachCardTilt` 未挂载（`(hover:hover) and (pointer:fine)` 不满足）→ 无倾斜、`--par-*` 恒为 0 |
| 系统「减弱动态效果」 | 同上不挂载；另用 `@media (prefers-reduced-motion: reduce)` 把 `transform` 归零 |
| 无封面 / 空合集 | `.cover-media.is-placeholder` 关闭视差（占位图标漂移显得廉价），纱罩与内框照常 |
| 超长合集名 | 书名单行 `text-overflow: ellipsis`，不换行、不撑高卡片（书名行高固定 → 尺寸对齐不被破坏）；完整名称走 CardTip |
| 指针停在卡片内不动、页面滚动 | 不产生 `pointermove`，偏移保持不变；滚动触发 `pointerleave`/`blur` 时复位 |
| 窗口缩放导致卡片宽高变化 | 复用既有 `offsetWidth != layoutWidth` 重测逻辑；视差是百分比，随卡宽自动等比缩放 |
| 卡片被 `v-for` 卸载 | `onBeforeUnmount → detach()` 移除全部监听与内联变量 |
| 点击书名行 / 徽章 | 装饰层 `pointer-events: none` 且 `aria-hidden`；书名行只挂 pointer 事件，点击冒泡到根节点打开合集 |
| 100+ 卡片同屏 | 视差只在 hovered 卡片上有非零值，`will-change` 只在 `.is-tilting` 期间声明 |

### 4.5 尺寸对齐推导（v3）

书卡高度（border-box）：

```
H_book = 2（卡描边）+ 16（8+8 内边距）+ 6（flex gap）+ (4/3)·(W − 18)（3:4 封面）+ TH（书名行）
       = (4/3)·W + TH
```

合集卡没有内边距，封面画幅更宽（W − 2），若只用 `aspect-ratio` 会正好比书卡矮「书名行 + 间距」。因此改为：

```
::before  aspect-ratio 3/4, width 100%  →  (4/3)·(W − 2)
::before  margin-bottom: -10px           →  抵掉书名行底部内边距
.card-title-row  padding-bottom: 10px    →  在流内占位 TH + 10

H_coll = 2 + (4/3)·(W − 2) − 10 + (TH + 10) = (4/3)·W + TH − 2/3
```

两者相差 **2/3 px**（亚像素，不可见），且与列宽无关——任何窗口宽度都保持齐平。

配合 `.collection-card { gap: 0 }`（全局 `.tilt-card` 是 6px）与 `.cover { position: absolute; inset: 0 }`：`::before` 只负责撑高，封面绝对定位后铺满整张卡（含书名行所占的底部空间），书名行靠 `position: relative; z-index: 1` 压在封面之上。

## 十、风险与取舍记录

| 项 | 取舍 | 影响与备注 |
|---|---|---|
| 倾角力度 | 10°（demo 15°，用户实机下调） | 15° 下 13px 白字重采样发虚明显，10° 是“明显深于书卡、书名仍可读”的交点；若还嫌糊可再降到 8°，若想要 demo 原味则回调 15°（改一个入参） |
| 透视视距 560px | 按卡宽比例换算 | 固定 900px 会使小卡的透视收缩不足、看着仍浅；代价是极端角度下封面边缘更易出现锯齿 |
| 视差百分比 + 22% 预放大 | 位移需求决定 | 位移 ≈17px 必须由 18px 预放大兜底，封面画面因此被放大裁切约 22%（demo 16.7%）；若觉得裁太多，把 8.333%/6.25% 同比降到 6%/4.5%，预放大可同步回到 14px |
| 尺寸靠 `::before` 撑高 | 与书卡结构解耦 | 书卡若改内边距 / 间距 / 书名字号，合集卡高度会随之失配（公式见 §4.5），需要同步改 `margin-bottom:-10px` 与 `padding-bottom:10px` 两个常量 |
| 封面铺满后与书卡不同构 | 合集卡 = 封面卡，书卡 = 封面 + 书名行 | 外框严格等高，但合集卡封面比书卡封面宽 16px、高 21px，属有意区分 |
| 卡壳内沿圆角对齐 | 封面 `calc(12px - 1px)` | 极少数缩放下可能出现 1px 亚像素缝；若出现，改为卡壳 `overflow: hidden` + 封面圆角 11px 兜底 |
| 倾斜 + 图层位移的「双层运动」 | 画面 17px，纱罩 / 文字全静止 | 若实际观感偏晃，把百分比常量下调即可，不影响逻辑层 |
| 每帧多写 2 个变量 | 所有卡片都写，只有合集卡消费 | 单张 hovered 卡片每帧 6 次 `setProperty`，无响应式更新，开销可忽略 |
| 共享纯函数被改动 | 只追加字段、倾角数值逐位不变 | 既有倾角断言不改即可证明无回归；新增「倾角与偏移同源」断言防漂移 |
| 不做 preserve-3d | 屏幕空间 2D 视差 | 视觉效果等价，避免徽章 `backdrop-filter` 在 3D 上下文里的额外合成开销（既有决策） |
| 卡内 hover 正文 | 不做 | 3D 重采样发虚是已修复过的真问题；信息需求由 CardTip 覆盖 |
| 空合集占位不参与视差 | `.is-placeholder` 关闭位移 | 图标漂移显得廉价；占位状态下深度只由倾斜、投影与内框表达 |
