# 阅读页翻页动画快速翻页响应优化设计方案

> 状态：设计稿（待确认）
> 目标版本：v1.2.6（沿用 `package.json` 当前 version，发版时由用户自行升级）
> 范围：PDF / EPUB 两个阅读引擎的翻页动画调度（快速连翻瞬切、覆盖层单例、快照与预取节流），不含卷曲视觉与设置项改动
> 实现约束：遵循 `ireader-dev-tasks`（任务 E 阅读器行为 / 任务 F 验证流程）与 `ireader-code-conventions`（中文注释、纯逻辑单测、工程红线）；本次无 IPC / DB 契约变更

## 一、需求拆解与验收标准

| # | 原始需求 | 设计落点 | 验收方式 |
|---|---|---|---|
| 1 | 快速翻页时每一次输入都要被响应，页码准确 | PDF：`ReaderView.vue` 的翻页回调改为「世代号 + 最新请求胜出」的单轮次管线；EPUB：`EpubReaderView.vue` 改为「净位移队列 + 串行消费」 | 连按 PageDown 20 次（≤1s）后，底栏页码/百分比精确前进 20 次，画面与指示一致 |
| 2 | 快速翻页时不允许动画叠加、蒙层残留 | 新增 `turnAnimator.ts` 全局单例覆盖层：每次播放先揭除上一条；PDF 每轮次开头无条件揭除；EPUB 输入即揭除在播卷曲 | 连翻全程肉眼/录屏最多一条卷曲；停手后无覆盖层、无冻结帧残留 |
| 3 | 快速连翻时动画不再「重头播 / 迟到」，跟手优先 | 新增 `turnPolicy.ts`：间隔 <160ms 或已有卷曲在播 → 瞬切；瞬切后 500ms 内持续瞬切；目标页就绪超过启动预算则放弃补播动画 | 连翻期间画面即时切换；停手 ≥500ms 后单次翻页恢复完整 450ms 卷曲 |
| 4 | 快速连翻时不再卡顿（主线程） | 瞬切路径不做任何全屏快照、跳过位图淡入；预取改为「停手 150ms 后启动 + 可取消 + 单并发」 | DevTools Performance 录制连按 20 次：无 >50ms 长任务（中端机），帧率稳定 |
| 5 | EPUB 快速连翻不与 epub.js 导航重叠、不截到重建画面 | 串行队列 + 净位移一次到位（`goTo`）；只有队列空闲时才走截图/卷曲编排 | 连按 10 次无白屏、无重复跳页、最终位置正确；CFI 正确落盘 |
| 6 | 保持既有语义（滑块、减弱动态、首尾页） | 滑块拖动瞬切 + 松手补播一次不变；`reducedMotion` 全程瞬切；未发生位移不播 | 冒烟清单逐条核对，与当前行为一致 |
| 7 | 附带修正：模式/方向切换不误播翻页动画 | `reader` store 新增 `navCount`，视图以「导航信号」而非 `firstPage` 差值判定 `isPageTurn` | 切单/双页、切阅读方向时无卷曲动画；正常翻页动画不受影响 |

**核心验收口径**：1 秒内连发 20 次翻页输入 → 最终位置精确前进 20 次（到边界则停在边界）；期间最多一条卷曲覆盖层、无蒙层/冻结帧残留、无白屏，Performance 面板无 >50ms 长任务；停手 ≥500ms 后单次翻页播放完整 450ms 卷曲；正常阅读（每页间隔 ≥500ms）每次翻页都有动画。

## 二、非目标（本期不做）

1. **不改卷曲视觉**：`src/services/pageCurl.ts` 的 450ms 时长、`easeInOutCubic`、投影/暗化/高光参数零改动，本次只改「何时播、播给谁」。
2. **不做动画接力**：卷曲中途被打断时直接揭除并落到目标页（内容已一致），不做「从当前进度续播下一条」。
3. **不改滑块视觉语义**：PDF 拖动期间仍逐次更新起点快照、EPUB 仍 200ms 节流；松手补播唯一一次的语义与视觉不变（仅接入单例动画器与取消）。
4. **不新增设置项与 DB 字段**（用户已确认）：动画开关/速度不做，沿用系统「减弱动态效果」。
5. **不改 IPC 与主进程**：无新通道、无 `shared/types.ts` 契约变更、无 `electron/**` 改动。
6. **不改渲染参数**：pdf.js 渲染参数、`pageCache` 容量（12）、`preloadSpreads` 数量语义不变。
7. **不改 EPUB 引擎补丁**：`installPaginatedNavigation`、`installPrePaginatedFit`、`waitViewsSettled` 等逻辑不动。
8. **不改阅读计时与进度保存链路**；不做触摸手势、不做移动端适配。

## 三、总体设计

### 3.1 分层数据流

```
┌─ 输入层 ──────────────────────────────────────────────────────────────┐
│ 热区点击 / 键盘 / 滚轮 / 底栏上一页下一页 / 滑块                        │
└───────────────┬───────────────────────────────┬───────────────────────┘
                │ PDF                            │ EPUB
                ▼                                ▼
   watch(currentDisplayPages)            requestTurn(dir)
   runTurnPass()                         pendingDelta += ±1（合并）
   世代号 turnGen：最新请求胜出            drainTurns()：串行消费
                │                                │
                └──────────────┬─────────────────┘
                               ▼
              TurnPolicy.decide（纯逻辑，注入时钟）
       ┌───────────────────────┴────────────────────────┐
       │ animate                                        │ snap
       ▼                                                ▼
PDF：from 快照 → 渲染 → to 快照          PDF：只渲染最新页（无快照 / 无淡入）
EPUB：截图 → 冻结帧 → 导航 → 卷曲         EPUB：净位移 goTo 一次到位（无截图）
       │                                                │
       └──────────────► turnAnimator ◄──────────────────┘
                 全局单例覆盖层（isActive / cancel / done）
                               │
                               ▼
              pageCurl.playPageCurl（视觉零改动，450ms）
```

要点：

- **判定与执行分离**：`turnPolicy.ts` 只回答「本次播不播动画」，不碰 DOM；两个阅读器共用同一口径，便于 Vitest 覆盖阈值与状态机。
- **覆盖层单例**：`turnAnimator.ts` 保证全局只有一个覆盖层，并向策略提供 `isTurnCurlActive()`；PDF 现有 `curlHandle` 与 EPUB 现有 `curlHandle` 的状态漂移一并收口。
- **渲染与动画解耦**：瞬切路径直接渲染，不再为「可能被取消的动画」付费；只有确认要播动画才做全屏快照。
- **预取让路**：所有翻页轮次开始先取消预取计时/在飞渲染，渲染完成后再延迟 150ms 重新排程，确保连翻期间主线程优先服务当前页。

### 3.2 关键决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 快速连翻时的动画表现 | **瞬切**（无动画），停手 500ms 后恢复 | 用户已确认；连翻时诉求是页码跟手，卷曲需要两张全屏快照且无法低成本「接力」，瞬切还能避免打断卷曲的半帧跳变 |
| 覆盖范围 | **PDF 与 EPUB 都优化** | 用户已确认；两端共用判定与单例动画器，避免同一交互两种表现 |
| 是否新增设置项 | **不新增** | 用户已确认；沿用系统「减弱动态效果」，避免 DB/设置页改动，符合最小侵入 |
| 判定实现 | 独立纯逻辑 `TurnPolicy` 类，注入 `now` | 阈值与「连续翻页闩锁」是典型状态机，放视图里无法单测；两引擎共用口径 |
| 覆盖层管理 | `turnAnimator.ts` 模块级单例 | 单阅读页场景天然只有一个覆盖层；集中处理「自然结束/被取消」两种收尾，消除 `curlHandle` 结束后不自清导致的误判 |
| PDF 轮次调度 | 世代号 + 最新请求胜出，过期轮次在检查点退出 | 现有 `watch` 的 async 回调并发执行，是双动画/错误 `resetPageScroll`/重复渲染的根因 |
| EPUB 调度 | 净位移队列 + 权威 `navIndex` | epub.js 导航不可取消，只能串行；10 次输入合并为一次 `goTo`，避免 10 次视图重建 |
| 动画启动预算 | PDF 220ms / EPUB 320ms | 超预算即放弃补播：迟到的动画与输入脱节，直接显示更跟手；正常阅读靠预取命中，预算内不受影响 |
| 预取策略 | 停手 150ms 后启动、单并发、可取消 | 现有预取只作废 token 不取消已提交的 pdf.js 渲染，连翻时会与当前页渲染抢主线程 |
| 翻页判定信号 | `reader` store 新增 `navCount`，仅 `goTo` 递增 | 现有以 `firstPage` 差值判定，会把「单→双页切换导致页组重排」误判为翻页并播反向卷曲，与新调度冲突 |
| 阈值落点 | 集中在 `turnPolicy.ts` 顶部导出常量 | 阈值偏主观，实测后只改一处；与 `wheelScroll.ts` 的 `GESTURE_GAP_MS` 风格一致 |

## 四、核心算法与边界防护

### 4.1 TurnPolicy（连续翻页判定）

```ts
/** 连续翻页判定：相邻翻页间隔小于该值视为连翻（ms） */
export const RAPID_GAP_MS = 160
/** 连翻后静默多久恢复动画（ms）；约等于卷曲时长 450ms + 余量 */
export const RAPID_QUIET_MS = 500
/** 目标页就绪超过该值则放弃补播动画（PDF，ms） */
export const PDF_ANIM_BUDGET_MS = 220
/** 同上，含截图 + epub.js 视图重建（EPUB，ms） */
export const EPUB_ANIM_BUDGET_MS = 320

export interface TurnPolicyInput {
  now: number                  // performance.now()
  isPageTurn: boolean          // 是否发生页组切换（false = 模式/方向/缩放切换）
  indexDelta: number           // 相对屏幕已绘制页组的索引差（页组数，可负）
  animating: boolean           // isTurnCurlActive()
  reducedMotion: boolean
  dragging: boolean            // 滑块拖动中
}

export class TurnPolicy {
  constructor(options?: { rapidGapMs?: number; quietMs?: number })
  decide(input: TurnPolicyInput): { mode: 'animate' | 'snap'; burst: boolean }
  reset(): void                // 换书 / 离开阅读页
}

// decide 逻辑：
// 1. !isPageTurn || reducedMotion || dragging → { snap, burst:false }，不记账
//     （重排/系统减弱动态/拖动都不算用户翻页，不能污染连翻闩锁）
// 2. rapid = animating
//          || Math.abs(indexDelta) !== 1
//          || (lastTurnAt !== null && now - lastTurnAt < rapidGapMs)
//          || now < burstUntil
// 3. lastTurnAt = now
// 4. rapid → burstUntil = now + quietMs，返回 { snap, burst:true }
//    否则返回 { animate, burst:false }
```

判定矩阵：

| 本次输入情形 | `mode` | `burst` | 说明 |
|---|---|---|---|
| 空闲后首次翻页（单页组前进/后退） | animate | false | 播放完整 450ms 卷曲 |
| 距上次翻页 <160ms | snap | true | 连翻开始，闩锁 500ms |
| 时长在播（间隔任意） | snap | true | 立即揭除旧卷曲，避免叠层 |
| 一次跳多个页组（Home/End/合并连翻） | snap | true | 不做长距离卷曲 |
| 闩锁期内（距上次瞬切 <500ms） | snap | true | 持续瞬切，不闪烁 |
| 模式/方向/缩放切换（`isPageTurn=false`） | snap | false | 不记账，随后首次翻页仍可播 |
| 系统减弱动态 / 滑块拖动 | snap | false | 语义直通 |

### 4.2 PDF 翻页轮次

```ts
/** 屏幕当前已绘制页组（动画基准）；null = 尚未绘制 */
let shown: { index: number; firstPage: number; navCount: number } | null = null
/** 请求世代号：新请求到达即递增，旧轮次在检查点退出 */
let turnGen = 0
/** 书本已打开并完成首帧渲染 */
let bookReady = false
const policy = new TurnPolicy()

watch(currentDisplayPages, () => void runTurnPass())

async function runTurnPass(): Promise<void> {
  const gen = ++turnGen
  if (!bookReady) return                    // 开书首帧由 openBook 负责
  const startedAt = performance.now()
  const index = reader.currentIndex
  const spread = reader.spreads[index]
  if (!spread) return

  cancelPrefetch()                          // 连翻时不给预取抢主线程

  // 滑块兜底：change 丢失时 1s 后自动退出拖动态（现有 sliderUntil 只在判定里读过，实际未生效）
  if (sliderActive && Date.now() > sliderUntil) sliderActive = false

  if (sliderActive) {                       // 把现有 L329-342 的零渲染块抽成 renderSliderFrame()
    renderSliderFrame()
    return
  }

  // 任何轮次（翻页、模式/方向切换、缩放重排）都先揭除旧覆盖层：
  // 旧卷曲的几何与像素已过期，绝不允许跨轮次残留
  const wasAnimating = isTurnCurlActive() // 揭除前取样，供策略判定「连翻」
  cancelTurnCurl()

  const isPageTurn = !!shown && reader.navCount !== shown.navCount
  const indexDelta = shown ? index - shown.index : 0
  const decision = policy.decide({
    now: startedAt,
    isPageTurn,
    indexDelta,
    animating: wasAnimating,
    reducedMotion,
    dragging: false,
  })

  const viewport = decision.mode === 'animate' ? isVerticallyScrollable() : false
  const fromSnap = decision.mode === 'animate' ? snapshotForTurn(viewport) : null

  await nextTick()
  if (gen !== turnGen) return               // 更新请求已接管：不做任何收尾动作
  const painted = await renderCurrentSpread({ fade: !decision.burst })
  if (gen !== turnGen || !painted) return

  if (isPageTurn) resetPageScroll(indexDelta > 0 ? 'top' : 'bottom')
  if (!fromSnap || performance.now() - startedAt > PDF_ANIM_BUDGET_MS) return

  const target = viewport ? pageAreaEl.value : pageContentEl.value
  const toSnap = target ? snapshotForTurn(viewport) : null
  if (!toSnap || !target || !rootEl.value) return

  playTurnCurl({
    container: rootEl.value,
    target,
    from: fromSnap,
    to: toSnap,
    fromRight: (indexDelta > 0) === (reader.direction === 'ltr'),
    zIndex: 1,
  })
}
```

配套调整：

- `renderCurrentSpread(options?: { fade?: boolean }): Promise<boolean>`：渲染开始时捕获 `pages/index/navCount`，全部贴图且 `seq === renderSeq` 时更新 `shown`、排程预取并返回 `true`；被新一轮作废则返回 `false`（不更新 `shown`）。
- `blit(src, dst, fade)`：`fade=false` 时只写位图、不强制 reflow、不重播 `canvas-in` 淡入（瞬切路径用）。
- `openBook()`：成功后置 `bookReady = true`；`doOpen()` 开头置 `false`、`shown = null`、`policy.reset()`、`cancelTurnCurl()`、`cancelPrefetch()`。
- `onResize()` / 缩放 watch：先 `cancelTurnCurl()` + `cancelPrefetch()`，再重渲染（几何已变，旧覆盖层必须揭除）。
- 动画结束不再依赖 `curlHandle` 自清：`turnAnimator` 在自然结束与取消两种情况下都会清空内部状态。

### 4.3 EPUB 净位移队列

```ts
let pendingDelta = 0            // 待执行净位移：每次输入 ±1，合并
let drainPromise: Promise<void> | null = null   // 进行中的队列消费（串行，杜绝导航重叠）
let navIndex: number | null = null   // 权威页索引：由队列推演，每次导航后以 relocated 校正
let openSeq = 0                 // 换书/尺寸变化/卸载时递增，旧流程在检查点退出
let forceSnap = false           // 下一次消费强制瞬切（滑块/Home/End 等显式跳转）
const policy = new TurnPolicy()

function requestTurn(dir: 'forward' | 'back'): void {
  if (!store.ready) return
  pendingDelta += dir === 'forward' ? 1 : -1
  if (isTurnCurlActive()) discardTurn()   // 立即揭除：底层已是动画终点，队列尽快消费本次输入
  void drainTurns()
}

/** 显式跳转（滑块节流跳页 / Home / End）：并入队列串行执行且强制瞬切；返回「队列已空闲」 */
function requestJump(index: number): Promise<void> {
  if (!store.ready) return Promise.resolve()
  const from = navIndex ?? store.current?.index ?? 0
  if (index !== from) {
    forceSnap = true
    pendingDelta = index - from
  }
  return drainTurns()
}

/** 串行消费队列：重入复用同一 Promise，调用方可安全 await「队列空闲」 */
function drainTurns(): Promise<void> {
  if (!drainPromise) {
    const token = openSeq
    drainPromise = doDrainTurns(token).finally(() => {
      drainPromise = null
      if (pendingDelta !== 0) void drainTurns()   // 换书/尺寸抖动期间的新输入兜底，绝不丢步
    })
  }
  return drainPromise
}

async function doDrainTurns(token: number): Promise<void> {
  while (pendingDelta !== 0 && token === openSeq) {
    const delta = pendingDelta
    pendingDelta = 0
    const snapOnce = forceSnap   // 逐次消费：中途的新输入不再继承强制瞬切
    forceSnap = false
    const from = navIndex ?? store.current?.index ?? 0
    const target = clampIndex(from + delta)
    const effective = target - from
    navIndex = target
    if (effective === 0) continue       // 首/尾页：不导航、不动画

    const decision = snapOnce
      ? { mode: 'snap' as const, burst: false }
      : policy.decide({
          now: performance.now(),
          isPageTurn: true,
          indexDelta: effective,
          animating: isTurnCurlActive(),
          reducedMotion,
          dragging: sliderDragging,
        })
    if (decision.mode === 'animate' && Math.abs(effective) === 1) {
      await animatedTurn(effective, token)
    } else {
      discardTurn()
      await jumpTo(target, effective)
    }
  }
}

/** 净位移一次到位：图片型书或 locations 就绪时直接 goTo，否则逐页回退；落点以 relocated 为准 */
async function jumpTo(target: number, delta: number): Promise<void> {
  const relocated = waitNextRelocated()
  if (store.layout === 'pre-paginated' || (store.locationsReady && store.totalPages() > 0)) {
    await store.goTo(target)
  } else {
    for (let i = 0; i < Math.abs(delta); i++) {
      await (delta > 0 ? store.next() : store.prev())
    }
  }
  await relocated
  navIndex = store.current?.index ?? navIndex   // 以引擎实际落点校正推演值（文字型 location 边界）
}

/** 滑块松手：等队列把最终页上屏后，用拖动起始快照补播唯一一次卷曲（不再自行导航） */
async function finishSlideCurl(finalIndex: number): Promise<void> {
  const startIndex = slideStartIndex
  const startCfi = slideStartCfi
  const fromPromise = slideFromPromise
  slideStartIndex = null
  slideStartCfi = null
  slideFromPromise = null
  const token = openSeq
  await requestJump(finalIndex)          // 串行：与在飞导航合并，最终页上屏后才补播
  if (reducedMotion || !store.ready || startIndex == null || !fromPromise || token !== openSeq) return
  const from = await fromPromise
  const area = epubAreaEl.value
  const root = rootEl.value
  if (!from || !area || !root || !store.current) return
  if (store.current.cfi === startCfi) return   // 未发生位移：不播（保留现有 CFI 判重）
  const dir: 'forward' | 'back' = finalIndex > startIndex ? 'forward' : 'back'
  await playTurnCurl({
    container: root,
    target: area,
    from,
    fromRight: (dir === 'forward') === (store.direction === 'ltr'),
  }).done
}
```

`animatedTurn(delta, token)` 沿用现有 `turnPage` 的时序（截图 → 冻结帧 → 导航 → 等 relocated → 等图片 → 卷曲），差异仅在：

1. 截图前先确认「队列仍空闲」（`pendingDelta === 0`），否则直接瞬切；
2. 视图稳定后、播卷曲前再查一次 `pendingDelta !== 0`（期间来了新输入 → 不播迟到动画，交给队列）与 `performance.now() - startedAt > EPUB_ANIM_BUDGET_MS`；`relocated` 到达后以 `store.current.index` 校准 `navIndex`（`jumpTo` 已内建）；
3. 用 `await playTurnCurl({...}).done` 等待卷曲结束或被取消，队列才继续下一轮；
4. `discardTurn()` 统一做 `cancelTurnCurl() + removeFreeze() + captureHide = false`；
5. 滑块松手走 `finishSlideCurl`：先 `await requestJump(finalIndex)` 等最终页上屏，再补播一次卷曲；补播期间的新翻页由 `requestTurn` 揭除卷曲、队列继续消费，不会重复导航。

### 4.4 边界场景防护

| 场景 | 防护 |
|---|---|
| PDF 连翻时旧轮次仍在 `await` | 每个检查点比较 `gen !== turnGen` 直接返回，不做渲染收尾、不 `resetPageScroll`、不播动画 |
| PDF 动画中又来翻页 | 策略 `animating` → snap；轮次开头 `cancelTurnCurl()`，底下已是上一目标页 |
| PDF 换书 / 返回文库 | `bookReady=false` 期间轮次直接返回；`doOpen` 复位 `shown`/策略/动画/预取 |
| PDF 滑块 `change` 丢失 | 轮次开头用 `sliderUntil`（每次 input 刷新为 now+1s）自动退出拖动态，避免永远走零渲染路径 |
| PDF 目标页渲染超预算 | 放弃补播，页面已上屏；不阻塞后续输入 |
| PDF 快照失败（无 canvas / 无 target） | 跳过动画，正常显示新页 |
| PDF 动画期间 resize / 缩放 | 取消覆盖层 + 取消预取 + 以新几何重渲染 |
| EPUB 动画中又来输入 | `requestTurn` 立即取消卷曲（`.done` 兑现）→ 队列继续消费净位移 |
| EPUB 截图/导航期间又来输入 | 输入只累加 `pendingDelta`；`animatedTurn` 播前检测到 pending 即放弃动画 |
| EPUB 首/尾页 | `effective === 0` 直接跳过，不导航、不动画 |
| EPUB `locations` 未就绪 | `jumpTo` 回退逐次 `next/prev`，保证正确性（略慢） |
| EPUB 换书 / resize / 卸载 | `openSeq++` + `pendingDelta=0` + `navIndex` 重置 + `discardTurn()`；队列 finally 兜底重排程 |
| EPUB 截图失败 | `from=null` → 照常导航，不播动画 |
| 未发生位移（CFI 不变） | 揭除冻结帧，不播动画（保持现有判定） |
| 系统减弱动态 / 拖动中 | 策略直通 snap，不记账 |

## 六、交互行为设计

### 6.1 行为矩阵

| 用户操作节奏 | PDF 表现 | EPUB 表现 |
|---|---|---|
| 单次翻页，距上次 ≥500ms | 完整 450ms 卷曲 | 完整 450ms 卷曲 |
| 每 200–400ms 一次（中速） | 第一次卷曲，后续瞬切（卷曲被揭除） | 同左；队列合并净位移 |
| 每 ≤100ms 一次（连按/连滚） | 首次可能起卷，随即全部瞬切，页码即时跟随 | 首次可能起卷，随即全部瞬切；一次 `goTo` 走完全部净位移 |
| 停手 500ms 后再翻 | 恢复完整卷曲 | 恢复完整卷曲 |
| 滑块拖动 | 每步瞬切（全缓存才贴图），松手补播一次 | 200ms 节流瞬切，松手补播一次 |
| Home/End / 大跨度跳转 | 瞬切（`indexDelta≠±1`） | 瞬切 + 一次 `goTo` |
| 模式/方向切换 | 瞬切（`isPageTurn=false`），不再误播卷曲 | 不涉及（切版式走 store 现有逻辑） |
| 系统减弱动态效果 | 全程瞬切 | 全程瞬切 |

### 6.2 一次连翻的时序（PDF，20 次输入 / 1s）

```
t=0ms     输入#1：gate → animate；from 快照；nextTick；渲染（缓存命中）
t≈35ms    卷曲开始（450ms 时间线）
t=100ms   输入#2：#1 卷曲被揭除（画面=页 2，已渲染）；gate → snap + 闩锁至 600ms
t≈110ms   页 3 上屏（无快照、无淡入）
t=150ms   #3 … #20：每轮仅渲染最新页，中间页合并跳过
t≈1000ms  输入结束，最终页上屏；闩锁在最后一次输入 +500ms 后失效
t≈1600ms  下一次单独输入：完整 450ms 卷曲
```

### 6.3 页面 / 视觉

- 无新增页面、无新增组件、无新增视觉元素；页头/底栏/滑块布局零改动。
- 唯一可见差异：快速连翻时页面直接切换（无淡入、无卷曲），停手后恢复卷曲；属于本期目标行为。

## 十、风险与取舍记录

| 项 | 取舍 | 影响与备注 |
|---|---|---|
| 快速连翻无动画 | 跟手与正确性优先于「每翻必有动画」 | 中速（200–400ms/页）也会退化为瞬切；若实测过于激进，调大 `RAPID_QUIET_MS` 或调小 `RAPID_GAP_MS` |
| 打断即落页，不做接力 | 不做半程续播 | 会有一帧从半卷曲到平铺页的跳变，但内容一致、方向正确，优于重头播 |
| 阈值主观 | 160 / 500 / 220 / 320 / 150 | 全部集中导出，实测后一处调整；单测锁行为，不锁具体数值 |
| 预取延迟 150ms | 连翻时不让预取抢主线程 | 极慢盘、顺序阅读首读可能多一次未命中；正常阅读间隔 >150ms，预取仍赶得上 |
| 合并中间页 | 连翻只渲染最终页 | 中间页不渲染是预期（快速翻页时看不清也无意义）；缓存不写入中间页 |
| PDF 世代号合并 | 最新请求胜出，不做逐轮排队 | 极端输入下中间页的 `renderSeq` 被作废，已提交的 pdf.js 渲染仍会自行结束（对同一 canvas 的重入会取消） |
| EPUB 净位移 `goTo` | 图片型 / locations 就绪时按索引跳 | `locations` 未就绪的短窗口回退逐次 `next/prev`，正确但略慢 |
| `navIndex` 与 relocated 漂移 | 每次导航等 relocated 后用 `store.current.index` 校正 | 文字型书的 location 边界可能让推演值偏一页；校正在该次导航完成后进行，不影响尚未消费的净位移 |
| 取消 pdf.js 渲染 | 复用现有 `RenderingCancelledException` 吞并 | 无副作用；取消后的 canvas 为空，token 检查保证不写入缓存 |
| 模式/方向切换不再播动画 | 修正原判定意图 | 旧实现会在「单→双页」时因 `firstPage` 变化播反向卷曲；新版以 `navCount` 为准 |
| 代价：新增 `navCount` 字段 | 仅渲染层 store，无持久化 | 不改变进度保存结构；`close()` 不重置也不影响跨书判定（`shown` 同步置空） |
| 代码熟悉度 | 两个视图的编排函数变多 | `turnPolicy` / `turnAnimator` 抽走后，视图只保留「取快照 → 渲染 → 播/不播」的直线流程，注释沿用中文分步说明 |
