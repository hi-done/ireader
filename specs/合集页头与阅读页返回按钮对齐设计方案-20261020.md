# 合集页头与阅读页返回按钮对齐设计方案

> 状态：设计稿
> 目标版本：1.2.6（版本号不变，由用户发版时确定）
> 范围：合集页页头内元素排版对齐设置页页头；阅读页（PDF / EPUB）工具栏返回按钮水平位置对齐设置页页头返回按钮
> 实现约束：遵循 `ireader-dev-tasks`（任务 D 渲染层样式、任务 E 阅读器界面、任务 F 验证）与 `ireader-code-conventions`（中文注释、样式单点、主题变量）

## 一、需求拆解与验收标准

| # | 原始需求 | 设计落点 | 验收方式 |
|---|----------|----------|----------|
| 1 | 合集页页头内元素格式排版参考设置页页头 | `.collection-head` 布局与标题字号上收全局、与 `.page-head` 合并为同一套规则；`.collection-head-info` 的 `align-items` 由 `baseline` 改为 `center`，标题 22px、meta 12px 与标题垂直中心对齐 | 合集页打开合集后：返回按钮与标题间距 20px；标题 22px；「合集 · N 本 · 按名称排序」与标题垂直居中；页头高度不变（约 72px） |
| 2 | 阅读页工具栏返回按钮位置参考设置页页头返回按钮位置 | PDF 与 EPUB 的 `.top-bar` 内边距由 `8px 16px` 改为 `8px 40px`，返回按钮左缘落点与设置页 `.page-head` 一致（非 mac 40px；mac 由全局避让规则同为 84px） | devtools 量取：设置页返回按钮左缘 X 与 PDF / EPUB 阅读页返回按钮左缘 X 相等；工具栏高度不变（约 46px） |
| 3 | 阅读页覆盖范围 | `ReaderView.vue`（PDF）与 `EpubReaderView.vue`（EPUB）同步修改 | 两种格式各打开一本书核对上一条 |

**核心验收口径**：同一窗口尺寸下，设置页、合集页、PDF 阅读页、EPUB 阅读页四处「← 返回」按钮的横向落点 X 坐标完全一致（非 mac 均为 40px、mac 均为 84px），且本次改动不改变任何页头 / 工具栏的既有高度。

## 二、非目标（本期不做）

- 不统一页头与阅读页工具栏的按钮尺寸 / 配色：阅读页是沉浸式黑底工具栏，按钮按 `padding: 4px 8px` 紧凑排布，只对齐位置不改形态。
- 不调整阅读页工具栏的上下内边距（保持 `8px`）：完全套用设置页的 `18px` 会使工具栏变高约 20px，破坏沉浸式观感（用户已确认仅水平对齐）。
- 不调整 `.bottom-bar`（PDF 页码栏 / EPUB 底部翻页栏）：本期只处理含返回按钮的顶部工具栏；上下栏左右留白差异若在验收中确认为问题，后续追加同值即可（单行改动）。
- 不给合集页头增加 sticky：文库视图整页不滚动（滚动发生在 `.book-grid` 内部），页头天然常驻顶部，无需吸顶语义。
- 不把页头抽成 Vue 共享组件：延续既有决策——页头是无状态纯展示块，样式单点归属全局 `src/style.css`，抽组件需要改两个视图的模板结构而收益低于成本。
- 不改动设置页 / 阅读统计页的模板：两者已直接使用全局 `.page-head`，本次仅重构其样式的定义位置（视觉等价）。

## 三、总体设计

纯渲染层样式改动，不涉及 IPC、数据库、store 与路由，数据流无变化。

### 3.1 对齐基准与现状差异

```
设置页（基准，全局 style.css）        合集页（现状，LibraryView scoped）
┌────────────────────────────┐      ┌──────────────────────────────────────┐
│ [← 返回]  设置              │      │ [← 返回]  标题  meta            [解散] │
│  ghost     h1 22px          │      │  ghost    22px  12px(baseline 对齐)    │
└────────────────────────────┘      └──────────────────────────────────────┘
  .page-head：flex / center / gap 20px / padding 18px 40px / 毛玻璃 / 底边
  ↑ 与 .collection-head 数值完全相同的两份定义，分别落在全局与视图 scoped
```

| 项 | 设置页 `.page-head` | 合集页 `.collection-head` | 结论 |
|----|--------------------|---------------------------|------|
| 布局容器 | flex / center / gap 20px / padding 18px 40px / 毛玻璃 / 底边 | 同 | 数值一致，但两份定义并存 |
| 标题 | `.page-head h1` 22px / 字距 -0.01em（字重走全局 h1 600） | `.collection-title` 22px / 600 / -0.01em | 数值一致，同样两份定义 |
| 标题区与附属信息 | 无附属信息 | `.collection-head-info` 内标题与 meta 同行、`align-items: baseline`、gap 12px | **不一致：meta 基线对齐，观感贴标题下沿** |
| 样式归属 | 全局 `src/style.css` 单点 | LibraryView scoped 副本 | **不一致：违反页头样式单点归属** |

### 3.2 关键决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 合集页头样式归属 | 布局与标题字号上收全局 `style.css`，与 `.page-head` 合并为同一选择器组 | `style.css` 的 `.platform-mac .collection-head` 避让规则本就引用该选择器，scoped 副本与之并存是既有隐患；本次需求本质就是两页头对齐，单点化后不会再漂移，且与「页头样式全局单点」的既有决策一致 |
| 合集页 meta 排版 | 保留同行，`align-items: baseline → center`，间距维持 12px | 用户确认；不增加页头高度，meta 与 22px 标题视觉中心对齐；12px 体现「标题 → 附属信息」的层级，不采用页头元素间距 20px |
| 阅读页水平口径 | `.top-bar` 内边距 `8px 16px → 8px 40px`（左右同改） | 左 40px 使返回按钮落点与设置页一致；左右等宽保证 flex:1 标题仍居中，只改左侧会使标题视觉中心右偏 |
| 阅读页垂直口径 | 保持 `8px` | 用户确认「仅水平对齐」；沉浸式工具栏维持紧凑高度 |
| 阅读引擎范围 | PDF 与 EPUB 同步 | 用户确认；两套 `.top-bar` 是各自 scoped 的等价副本，同批修改保证体验一致 |
| macOS 避让 | 沿用全局 `.platform-mac .top-bar { padding-left: 84px }` | 与 `.page-head` / `.collection-head` 同一套红绿灯避让规则，无需新增平台分支 |

## 四、对齐口径与尺寸推导

### 4.1 横向落点

| 场景 | 设置页返回按钮左缘 | 阅读页返回按钮左缘（改后） |
|------|--------------------|------------------------------|
| 非 mac | `padding-left: 40px` | `.top-bar` `padding-left: 40px` |
| mac | 全局避让 `padding-left: 84px` | 全局避让 `padding-left: 84px`（`.platform-mac .top-bar`，特异性更高，覆盖组件的 40px） |

- 阅读页右内边距同步改 40px：`.top-bar` 的标题是 `flex: 1; text-align: center`，左右内边距不等会让标题中心偏离窗口中心。
- mac 下左 84 / 右 40 的不对称与设置页页头一致，属红绿灯避让的既有取舍。

### 4.2 高度不变量（验收用）

| 元素 | 高度推导 | 改前 / 改后 |
|------|----------|-------------|
| 页头（设置页 / 合集页） | `padding 18×2 + max(标题行高 22×1.25=27.5, 返回按钮 20.25+14+2≈36.25) ≈ 72px` | 不变（只加上收与对齐，不改内边距） |
| 阅读页 `.top-bar` | `padding 8×2 + 按钮 20.25+8+2≈30.25 ≈ 46px` | 不变（只改左右内边距） |

### 4.3 边界与窄窗

| 场景 | 处理 |
|------|------|
| 窗口很窄 | `.top-bar` 固定内容约 480px（返回 / 上一本 / 下一本 / 控件组）+ 左右内边距 80px；窗口宽低于约 620px 时标题区先被压缩至 0，再溢出。`main.ts` 未设 `minWidth`，属既有风险，本期不引入窗口最小宽度（超出范围），见第十章 |
| 合集标题极长 | `.collection-title` 保留 `min-width: 0` 容器内的省略号，与改前一致；meta 与「解散合集」按钮均为 `flex-shrink: 0` |
| 深浅主题 | 全部沿用 `--surface-alpha` / `--border` / `--text-muted` / `--danger` 变量，无新增色值 |

## 五、渲染层实现

### 5.1 `src/style.css`：页头布局单点化

将现有 `.page-head` 块拆为「共享布局」与「吸顶差异」两段，并把 `.collection-head` 纳入共享选择器；标题字号选择器合并 `.page-head h1` 与 `.collection-title`：

```css
/* 页面头（二级页 / 文库合集页）：布局单点定义；视图 scoped 只保留差异部分。
   吸顶仅二级页需要（文库视图整页不滚动，合集头天然常驻顶部） */
.page-head,
.collection-head {
  display: flex;
  align-items: center;
  gap: 20px;
  padding: 18px 40px;
  background: var(--surface-alpha);
  backdrop-filter: blur(20px) saturate(180%);
  border-bottom: 1px solid var(--border);
}

.page-head {
  position: sticky;
  top: 0;
  /* z-index 10：高于内容层，低于图表 tooltip(30) / 对话框(100) / toast(200) */
  z-index: 10;
}

.page-head h1,
.collection-title {
  font-size: 22px;
  letter-spacing: -0.01em;
}
```

- 既有 `.platform-mac .top-bar, .platform-mac .collection-head, .platform-mac .page-head { padding-left: 84px }` 不动，合并后规则特异性低一档，mac 避让继续生效。
- 现有 `.page-head` 的注释（吸顶与层级说明）随块拆分移动到 `.page-head` 独立段。

### 5.2 `src/views/LibraryView.vue`：合集页头对齐

| 位置 | 改动 |
|------|------|
| scoped `.collection-head` 整块 | 删除（布局已上收全局），视图内不再保留同名副本 |
| scoped `.collection-title` | 删除 `font-size` / `font-weight` / `letter-spacing` 重复声明，保留 `margin: 0`、`overflow: hidden`、`text-overflow: ellipsis`、`white-space: nowrap` |
| scoped `.collection-head-info` | `align-items: baseline` → `center`；其余（`flex: 1`、`min-width: 0`、`display: flex`、`gap: 12px`）不变 |
| 模板 | 不改动（`<header class="collection-head">` 结构保持） |

改动后合集页头内元素垂直关系：返回按钮（36px 高）、标题（27.5px 行高）、meta（18px 行高）三者按 `align-items: center` 垂直居中于同一行，meta 不再贴标题基线。

### 5.3 `src/views/ReaderView.vue` / `src/views/EpubReaderView.vue`：工具栏水平对齐

两个视图 scoped 中的共享块保持原样：

```css
.top-bar,
.bottom-bar {
  /* …… 既有声明不动，padding: 8px 16px 继续服务 bottom-bar …… */
}
```

在紧随其后的 `.top-bar` 段追加左右内边距覆盖：

```css
.top-bar {
  top: 0;
  /* 返回按钮水平落点对齐设置页页头：非 mac 左 40px；mac 由全局 .platform-mac .top-bar 覆盖为 84px */
  padding: 8px 40px;
}
```

- 两个文件写法完全一致，各自 scoped，互不依赖。
- `.icon-btn` 的尺寸、边框、配色不动。

## 六、页面 / 交互设计

### 6.1 合集页头（改前 → 改后）

```
改前（meta 基线对齐，贴标题下沿）：
┌──────────────────────────────────────────────────────────────────┐
│ [← 返回]  咒术回战 ────────────────────────────────  [解散合集]    │
│            22px  合集 · 6 本 · 按名称排序（12px，基线对齐）          │
└──────────────────────────────────────────────────────────────────┘

改后（三者垂直中心对齐）：
┌──────────────────────────────────────────────────────────────────┐
│ [← 返回]  咒术回战  合集 · 6 本 · 按名称排序        [解散合集]      │
│            22px    12px（垂直居中）                                │
└──────────────────────────────────────────────────────────────────┘
```

- 返回按钮与标题间距 20px（页头共享 `gap`）；标题与 meta 间距 12px（`collection-head-info` 的 `gap`）。
- 「解散合集」仍在最右，`margin-left: auto` 效果由 `.collection-head-info { flex: 1 }` 提供，不变。
- 页头高度保持约 72px，滚动行为、毛玻璃、底部分割线不变。

### 6.2 阅读页顶部工具栏（改前 → 改后）

```
改前：│← 返回  标题（居中）  ‹上一本 下一本›  [单页][左→右][适宽][⛶]│  ← 左右留白 16px
改后：│  ← 返回  标题（居中） ‹上一本 下一本›  [单页][左→右][适宽][⛶]  │  ← 左右留白 40px
```

- 工具栏整体仍贴顶显示，高度约 46px 不变；返回按钮距屏幕顶部距离不变（垂直位置不属于本次需求）。
- 设置页、合集页、阅读页三处返回按钮在非 mac 下左缘同为 40px，mac 下同为 84px。
- 空态 / 加载态 / 错误态无变化（错误态「返回文库」按钮位于内容区，不在工具栏）。

## 十、风险与取舍记录

| 项 | 取舍 | 影响与备注 |
|----|------|------------|
| `.collection-head` 上收全局 | 新增一条全局选择器 | 当前仅 LibraryView 使用；若未来出现同名类会套用页头样式，命名时需避开 |
| 阅读页左右内边距同改 40px | 略超出「只改返回按钮位置」的字面要求 | 保证 `flex: 1` 标题居中不偏；如需最小改动可只改左侧，但标题中心会右移约 12px |
| `.bottom-bar` 保持 16px | 阅读页上下工具栏左右留白不一致（40 vs 16） | 范围最小化；视觉验收若认为不齐，追加同样 `padding` 即可回退成本极低 |
| 窄窗压缩标题区 | 不引入 `minWidth` | 属既有问题（`main.ts` 未设最小窗口尺寸）；本次只增加 48px 固定占位，临界宽度约 620px |
| 标题字号依赖 `h1` 元素 | `.collection-title` 选择器只设字号字距，字重靠全局 `h1` | LibraryView 标题现为 `<h1>`；若未来改为 `div` 会丢 600 字重，需同步补声明 |
| 不抽共享页头组件 | 继续用全局样式单点 | 页头无 props / 插槽，组件化收益低于改模板成本（沿用 4cb46fd 决策） |
