# 设置与统计页视觉优化设计方案

> 状态：设计稿（待实现）
> 目标版本：v1.2.0（随未发布的阅读时间统计功能同批；本次仅提交代码，不 bump 版本、不打 tag）
> 范围：设置页 / 阅读统计页的按钮风格统一精修、页头样式单点化与尺寸对齐、全局按钮状态缺陷修复（禁用态悬停）
> 实现约束：遵循 `ireader-dev-tasks`（任务 D 第 4 条：样式跟随主题体系，兼容 light/dark；任务 F 验证流程）与 `ireader-code-conventions`（中文注释、与相邻文件风格一致）

## 一、需求拆解与验收标准

| # | 原始需求 | 设计落点 | 验收方式 |
|---|----------|----------|----------|
| 1 | 优化设置页按钮风格效果 | 「阅读时间统计」入口行（`.row-link`）过渡链修复：文字与 chevron 同步渐变（现状文字跳色无过渡、chevron 恒为灰色不参与 hover 变色） | hover 入口行：文字与箭头同帧渐变到品牌色，移出后回落，全程无跳变 |
| 2 | 优化统计页按钮风格效果 | 7/30 天分段控件（`.seg`）：字号对齐小号刻度 12.5px、补未选中 hover、焦点环适配；错误态「重试」归入主按钮（`.primary`） | 分段控件悬停/切换/键盘焦点反馈明确；错误态重试为品牌蓝填充 |
| 3 | 页头文字等尺寸统一 | `.page-head` 从两视图 scoped 样式收敛为 `style.css` 单点共享，规范对齐 `.collection-head`（18px 40px 内边距、gap 20px、底部分割线）；标题保持 22px 并统一 -0.01em 字距 | 两页页头逐项一致、与文库合集头同规范；macOS 红绿灯避让规则不受影响 |
| 4 | 全局按钮体系保持协调（用户选定全局方案） | `style.css` 三级按钮仅做缺陷修复（禁用态悬停守卫）与 `user-select` 加固，形态/尺寸/圆角零变化 | 文库页与对话框除「禁用按钮不再响应悬停变色」外视觉零变化 |

**核心验收口径**：两页在浅色 / 深色主题下，页头与 `.collection-head` 逐项同规范、按钮各状态符合 §4 状态矩阵；`npm run typecheck`、`npm test` 通过；文库页与各对话框除禁用态修复外零视觉变化。

## 二、非目标（本期不做）

- 不做按钮形态变化（胶囊化、渐变、阴影、缩放回弹）——用户在决策中选定「统一精修」而非「质感升级」「形态调整」。
- 不做页头吸顶（sticky）——属行为变更，超出按钮/页头样式范畴。
- 不统一卡片圆角（设置页 `.group-card` 10px 与统计页 `.panel` / `StatCard` 14px 并存）与内容区宽度/对齐策略（设置 640px 左对齐、统计 880px 居中）——超出本次范畴，留待未来全局视觉审计。
- 不改导航行为（`router.back()` 与 `router.push('/')` 并存现状）与路由配置。
- 不改 `DailyBarChart` / `StatCard` / `BookRankingList` / `StatsEmptyState` 的既有动效与结构。
- 不新增 npm 依赖；不涉及 IPC 契约、DB、共享类型。

## 三、总体设计

### 3.1 样式归属与变更结构

```
style.css（全局单点）
 ├─ 按钮三级体系（default / ghost / primary / danger-fill）
 │    └─ 修复：hover 全部施加 :not(:disabled) 守卫（禁用按钮不再悬停变色）
 │    └─ 加固：button { user-select: none }（防双击选中按钮文字）
 └─ .page-head 共享页头 ← 由两视图 scoped 迁移（对齐 .collection-head 规范）
        ▲                              ▲
        │ 删除 scoped 副本              │ 删除 scoped 副本
 SettingsView.vue              ReadingStatsView.vue
   └─ .row-link 过渡链修复          ├─ .seg 分段控件精修（字号/hover/焦点）
      （.row-value + .chevron）      └─ 错误态「重试」加 class="primary"
```

无 IPC / 数据流变更，纯渲染层样式改动；样式变量全部取自 `style.css` 既有 CSS 变量，深浅主题自动兼容。

### 3.2 关键决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 页头样式归属 | 迁移至 `style.css` 单点维护 | 两页副本完全一致，且全局已有 `.platform-mac .page-head` 红绿灯规则引用该选择器，就近收敛，避免未来第三个页面再复制 |
| 页头内边距与结构 | 对齐 `.collection-head`（18px 40px、gap 20px、border-bottom 1px） | 应用内已有头部条既定规范（文库合集头），直接复用而非另立标准；标题尺寸保持不变（用户确认） |
| 标题字距 | -0.01em（对齐 `.collection-title`） | 消除同为 22px 的两处标题字距微差 |
| 按钮精修幅度 | 仅补状态缺口与统一小号刻度（12.5px），形态/尺寸/圆角不变 | 用户选定「统一精修」：修复不一致优先，每项改动可逐条指认，观感变化克制 |
| 分段控件 hover | 仅加深文字色、不加背景 | 防止未选中项出现「类选中」背景，牺牲少量反馈感换取选中态辨识度 |
| 全局悬停守卫 | `:hover:not(:disabled)` | 修复既有缺陷：现在禁用按钮仍会响应 `button:hover` 的背景变化（`button:disabled` 只覆盖了 transform 未覆盖背景），文库页「上一本/下一本」、对话框确认按钮同受益 |
| 版本节奏 | 目标 v1.2.0、本次不发版 | 用户确认：随未发布的阅读统计功能同批，版本号与 tag 由后续发版流程统一处理 |

## 四、视觉规范（本次核心口径）

### 4.1 尺寸刻度

| 层级 | 字号 / 字重 | 内边距 | 圆角 | 适用 |
|------|------------|--------|------|------|
| 标准按钮 | 13.5px / 500 | 7px 14px | 8px（`--radius`） | 全局默认、主按钮、ghost、重试、空态 CTA |
| 小号按钮（密集区） | 12.5px / 500 | 保持各组件现状（分段控件 4px 12px） | 分段控件外层 8px / 内钮 6px | 7/30 天分段控件（12→12.5px）、排行展开按钮（现状 12.5px 不动） |
| 页头标题 | 22px / 600 / 字距 -0.01em | — | — | 两页 `.page-head h1`（尺寸不变，仅补字距） |

### 4.2 按钮状态矩阵（全局，仅修复标注项）

| 状态 | 次级（默认） | 文字（ghost） | 主（primary） |
|------|-------------|--------------|---------------|
| 静默 | bg `--surface` / border `--border` / `--text` | 透明 / 透明 / `--text-secondary` | `--brand` / `--brand` / #fff |
| 悬停 | bg `--surface-2` | bg `--surface-2` / 文字 `--text` | bg `--brand-hover` / border `--brand-hover` |
| 按下 | translateY(0.5px)，0.1s ease | 同左 | 同左 |
| 键盘焦点 | outline 2px `--brand`，offset 2px | 同左 | 同左 |
| 禁用 | opacity 0.45 / not-allowed / **无悬停变化（本次修复：hover 加 `:not(:disabled)`）** | 同左 | 同左 |

补充：`button { user-select: none }`（防双击选中按钮文字）；过渡曲线维持现状（背景/边框/文字 0.15s ease、transform 0.1s ease）。

### 4.3 分段控件（统计页局部 `.seg`）

- 按钮字号 12px → **12.5px**（对齐小号刻度），内边距与圆角不变。
- 未选中 `hover`：仅 `color: --text-secondary → --text`，不加背景（决策见 §3.2）。
- 键盘焦点：`outline-offset: 1px`（容器内衬仅 2px，默认 2px offset 会贴边过近）。
- 选中态维持现状：bg `--surface`、文字 `--text`、600 字重、`--shadow-sm`。

### 4.4 页头规范（全局单点，Style.css 新增块）

```css
/* 页面头（设置 / 阅读统计等二级页）：与 .collection-head 同规范 */
.page-head {
  display: flex;
  align-items: center;
  gap: 20px;
  padding: 18px 40px;
  background: var(--surface-alpha);
  backdrop-filter: blur(20px) saturate(180%);
  border-bottom: 1px solid var(--border);
}
.page-head h1 {
  font-size: 22px;
  letter-spacing: -0.01em;
}
```

- 与调整前差异：内边距 `24px 40px 8px` → `18px 40px`（页头整体高度 68px → 72px，约 +4px）、gap 16 → 20px、新增底部分割线。
- macOS 红绿灯避让沿用既有 `.platform-mac .page-head { padding-left: 84px }`（选择器优先于 `.page-head`，无需改动）。

## 九、风险与取舍记录

| 项 | 取舍 | 影响与备注 |
|----|------|------------|
| 页头高度 +4px（68→72px） | 对齐 `.collection-head` 要一致性 | 首屏内容下移约 4px，属可接受范围；如不适可单独微调 padding 一行回退 |
| 页头新增底部分割线 | 与既有头部条（collection-head / toolbar）规范一致 | 若观感偏重，删除 1 行即可回退 |
| 分段控件 hover 仅文字变色 | 交互反馈较弱，但避免未选中项出现「类选中」背景 | 选中态辨识度优先；如后续反馈反馈感不足，可单独为未选中补极浅背景（`--surface-2` 50% 透明度级） |
| 全局 `:hover:not(:disabled)` 修复 | 改变禁用按钮的悬停行为 | 正向修复既有不一致，影响面仅禁用态（文库页侧栏、对话框确认按钮），无回归风险 |
| 卡片圆角 10 / 14px 并存 | 本期不做统一 | 超出按钮/页头范畴（非目标）；留待未来一次全局视觉审计统一处理 |
| 暂不发版 | 仅提交代码，不 bump 版本、不打 tag | 与阅读统计功能同批作为 v1.2.0 发布内容，由发版流程统一处理版本号 |
