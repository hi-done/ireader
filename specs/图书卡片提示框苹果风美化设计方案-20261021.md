# 图书卡片提示框苹果风美化设计方案

> 状态：v1.2.6 已实现（v2，2026-10-21：提示框改为 Teleport 浮层，修复 3D 倾斜下的文字模糊；用户验收通过）
> 目标版本：v1.2.6（沿用当前 package.json 版本，本次不改版本号、不打 tag，由用户自行发版时确定）
> 范围：文库书卡片（`BookCard`）三个操作按钮的悬停提示、书名悬停提示（书名 + 阅读进度两行）、进度环的原生提示收敛；合集卡（`CollectionCard`）书名提示同步，保证同屏两类卡片一致
> 实现约束：遵循 `ireader-dev-tasks`（任务 D：渲染层组件归属与主题兼容；任务 F：验证流程）与 `ireader-code-conventions`（中文注释、颜色一律取 CSS 变量、不新增依赖、纯逻辑入 `src/services/` 并补 Vitest）

## 一、需求拆解与验收标准

| # | 原始需求 | 设计落点 | 验收方式 |
|---|----------|----------|----------|
| 1 | 操作按钮提示框美化，符合苹果系统风格 | 三个按钮移除原生 `title`，改由 `CardTip` 浮层绘制：6px 圆角、12.5px/500 字、无箭头、不透明底 + 1px 描边 + 投影（§五） | 悬停任一按钮不再出现 Windows 系统白框；提示框为紧贴按钮下方的圆角胶囊 |
| 2 | 书名提示框扩展 | `.title` 外层新增 `.card-title-row`，`CardTip` 的锚点即该行；悬停书名行出现完整书名，多行折行且宽度锁定为书名行宽（§5.4 / §5.5） | 悬停 20 字以上长书名卡片，提示框换行完整显示，左右不超出卡片、不触发 `.book-grid` 横向滚动条 |
| 3 | 阅读进度也扩展（用户确认：并入书名提示框） | 进度环删除 `title="阅读进度"`，改 `role="img"` + `aria-label="阅读进度 36%"`；书名提示框第二行渲染「阅读进度 N%」，仅 `progressPercent !== null` 时出现（§5.5） | 有进度的书卡：书名提示框两行，第二行为「阅读进度 36%」；无进度的书卡只有书名一行；悬停进度环区域只出现按钮提示，无原生白框 |
| 4 | 提示框随主题深浅两套材质（用户确认） | `src/style.css` 的 `:root` 与 `:root[data-theme='dark']` 各新增 4 个 `--tip-*` 令牌，浅色近白底深字、深色深底白字（§5.1） | 切换设置页主题后所有提示框底色 / 文字 / 描边同步切换 |
| 5 | 提示框不与原生提示叠弹 | 三个按钮 `title` → `aria-label`；书名与进度环的 `title` 直接移除（书名文本本身可被读屏读到） | 悬停三按钮、书名、进度环，均只出现自定义提示框；鼠标停留 2 秒无第二个系统提示 |
| 6 | 不破坏键盘可达与读屏语义 | 按钮补 `aria-label`；进度环 `role="img"` + `aria-label`；浮层 `aria-hidden="true"` 避免重复朗读；键盘路径用 `:focus-visible` 显示提示 | Tab 逐格聚焦三个按钮，提示框出现且读屏读出「移入合集 / 重命名 / 从文库移除」；读屏到进度环读出「阅读进度 36%」 |
| 7 | 提示框不裁切、不引入滚动条 | 浮层挂在 `body` 上，不参与卡片布局；移除钮提示右缘对齐、书名提示锁定书名行宽，再由 `resolveTipPosition` 收敛到视口安全边距（§4.4） | 逐列悬停网格最左 / 最右列卡片，`.book-grid` 不出现横向滚动条，提示框完整可见 |
| 8 | 苹果风的出现节奏 | hover / `focus-visible` 后延迟 350ms，140ms 缓入淡入 + 2px 位移；移出立即淡出；按钮按压时立即收起（§4.1） | 悬停约 0.35s 后提示框淡入；移出后立即消失；按住按钮时提示框不跟随缩小 |
| 9 | 文字必须锐利（v2 修复） | 浮层 `Teleport` 到 `body`，脱离 `.tilt-card` 的 `perspective + rotate` 3D 层；底色不透明、字号 12.5px、字重 500、`-webkit-font-smoothing: auto`（§3.2 / §5.2） | 鼠标悬停（卡片倾斜状态）与键盘 Tab（卡片回正状态）看到的提示框文字锐度一致，无发虚、无重影 |
| 10 | 不改变任何业务行为 | `open / remove / rename / move` 四个 emit、`@click.stop`、26px 圆钮尺寸与位置、图标、进度环 hover 让位一律不动 | 逐项回归：打开阅读器、移入合集、重命名、移除、合集进入 / 返回 |

**核心验收口径**：浅色与深色主题下，悬停书卡任一操作按钮 350ms ~ 500ms 内出现 6px 圆角、无箭头的提示框（浅色 `#fbfbfd` / 深色 `#2c2c2e`，均带 1px 描边与投影，文字 12.5px/500 且边缘锐利）；悬停书名行出现同材质提示框，书名完整折行、有进度时第二行为「阅读进度 N%」；全部提示框不产生横向滚动条、任何位置都不再弹出原生 tooltip；卡片处于 3D 倾斜时提示框文字不模糊；键盘 `Tab` 聚焦按钮时出现同一提示框；`npm run typecheck` 与 `npm test` 通过，文库网格以外的页面视觉零变化。

## 二、非目标（本期不做）

- 不替换阅读器工具栏（`ReaderView` / `EpubReaderView` 的上一本 / 下一本 / 缩放 / 全屏）与 `SelectMenu` 触发器的 `title`：跨视图改造已由《阅读器工具栏提示框苹果风美化设计方案-20261021.md》承接（复用本文档的 `--tip-*` 令牌与 `CardTip` 浮层，本文档范围内 `BookCard` / `CollectionCard` 的实现保持不变）。
- 不判断书名是否被截断（用户确认「始终显示」）：不做 `scrollWidth > clientWidth` 测量，不需要额外的测量逻辑与单测。
- 不为进度环提供独立的悬停提示：它在卡片 hover 时 180ms 内淡出、位置又被三个圆钮完全覆盖，没有可用悬停窗口，信息并入书名提示框第二行。
- 不做通用 Tooltip（不支持箭头、方向自适应翻转、延迟分组、`aria-describedby` 关联）：`CardTip` 只服务卡片内 5 处提示，API 保持最小。
- 不做滚动跟随：浮层显示期间发生滚动 / 窗口缩放即收起（与系统 tooltip 一致），不做逐帧重定位。
- 不做箭头 / 气泡尖角：macOS 的 help tag 无箭头，加箭头会与 26px 无方向毛玻璃圆钮的材质语言冲突。
- 不改按钮尺寸（26px）、位置（`top / right: 14px`）、间距（6px）、图标、hover 底色、`scale(0.94)` 按压反馈。
- 不改进度环的尺寸（36px）、材质、hover 淡出让位、环与数字的绘制。
- 不改 `LibraryView.vue` 网格列宽 / 间距 / 滚动容器，不改 `.tilt-card` 的 3D 倾斜与 `.cover` 的 `overflow: hidden`。
- 不新增 npm 依赖，不引入 `@floating-ui` 等定位库。
- 不做提示框富文本：书名提示只有「书名 + 阅读进度」两行，不含作者、页数等字段。

## 三、总体设计

### 3.1 结构与数据流

```
LibraryView.vue（.book-grid：overflow-y: auto，最小列宽 160px，卡片内容宽 142px）
  ├─ BookCard.vue（根 .book-card.tilt-card，position: relative，3D transform）
  │    ├─ .cover（3:4，overflow: hidden）
  │    │    ├─ img / .cover-placeholder
  │    │    ├─ .cover-glare
  │    │    ├─ .badge-missing.cover-badge
  │    │    └─ .progress-ring（role="img" + aria-label="阅读进度 36%"，title 删除）
  │    ├─ .card-title-row（hover 触发点；min-width: 0，无定位上下文职责）
  │    │    └─ .title（13px 单行省略，title 删除）
  │    ├─ .card-actions（position: absolute; top/right: 14px; flex; gap: 6px）
  │    │    ├─ button.action-btn.move-btn     aria-label=MOVE_LABEL
  │    │    ├─ button.action-btn.rename-btn   aria-label=RENAME_LABEL
  │    │    └─ button.action-btn.remove-btn   :aria-label="removeLabel"
  │    └─ <CardTip>（逻辑上挂在卡片内，DOM Teleport 到 body）
  │
  └─ CollectionCard.vue（根 .collection-card.tilt-card）
       ├─ .cover-stack（纸页缘 + .cover）
       └─ .card-title-row（hover 触发点）
            ├─ .title（title 删除）
            └─ <CardTip>

CardTip.vue（Teleport to="body"，position: fixed，z-index 40）
  └─ .app-tip（材质 / 字排 / 描边 / 投影 / 过渡）
       ├─ span  书名或按钮文案
       └─ span.app-tip-meta  阅读进度 N%（v-if 有进度，仅书名场景）

交互（零 hover 选择器，全部事件驱动）：
  pointerenter / focus-visible → BookCard 记下锚点元素与文案 → visible=true
    → CardTip 延迟 350ms → shown=true → nextTick 测量锚点矩形与浮层尺寸
    → resolveTipPosition()（纯函数）→ 写入 top / left / width
  pointerleave / blur / 按压 / 滚动 / 缩放 → visible=false（或 emit dismiss）→ 100ms 淡出
```

样式单点：
- `src/style.css`：`:root` / `:root[data-theme='dark']` 的 `--tip-*` 四个令牌 + `.card-title-row`（两卡共用的 hover 触发容器）
- `src/components/ui/CardTip.vue`（scoped）：`.app-tip` 材质与字排、`.app-tip--wrap` 多行、`.app-tip-meta` 进度行、`card-tip-*` 过渡类、减弱动效降级

无 IPC、无 DB、无 store、无 shared/types 改动；新增一个定位纯函数模块与一个展示组件，卡片侧只多一份提示状态。

### 3.2 关键决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 按钮改造范围（用户确认） | `BookCard` 三个操作按钮 | 回归面限一张卡片，按钮位置固定、无需测量 |
| 书名 / 进度范围（用户确认） | 书卡书名 + 进度并入书名框；合集卡书名同步 | 同屏两类卡片并排，只改一类会出现「书卡自定义、合集卡系统白框」的分裂 |
| 进度环处理（用户确认） | 删除 `title`，信息并入书名提示框第二行 | 进度环 hover 即淡出且被按钮覆盖，独立提示无可用窗口；并入后一处 hover 同时给出书名与进度 |
| 书名提示触发（用户确认） | 始终显示，不判断是否截断 | 不引入 `scrollWidth` 测量与额外监听；代价是完整书名也会重复一次（列入风险） |
| **浮层宿主（v2）** | `Teleport` 到 `body` + `position: fixed`，由脚本写坐标 | `.tilt-card` 的 `perspective(900px) rotateX/rotateY` 会把整层内容重采样：hover 时卡片倾斜（指针在右上角，角度最大），11~12px 文字明显发虚，而 Tab 聚焦（卡片不倾斜）时锐利。子元素无法脱离父级 3D 层的栅格化，只能换宿主 |
| **定位方式（v2）** | 纯函数 `resolveTipPosition` 计算锚点矩形 → fixed 坐标，再做视口钳制 | 逻辑与渲染分离、可单测；不用浮层库，符合「不新增依赖」；5 处提示共用同一算法 |
| 材质（v2 修正） | 不透明底（浅 `#fbfbfd` / 深 `#2c2c2e`），去掉 `backdrop-filter` | 半透明背景会强制关闭子像素抗锯齿，小字号本就发虚；0.94 不透明度下模糊本就不可见，取舍为「锐度优先，层次交给描边 + 投影」 |
| 字排（v2 修正） | 12.5px / 500 / `line-height: 1.4` / `-webkit-font-smoothing: auto` | 全局 `antialiased` 是 macOS 取向，Windows 下让中文小字变细发虚，提示框局部覆盖回系统默认渲染 |
| 书名提示结构 | 新增 `.card-title-row` 包裹 `.title`，作为 hover 触发点与锚点 | `.title` 自带 `overflow: hidden`，但与浮层已无父子关系；包裹层提供「书名整行」这个稳定的锚点矩形（锚点宽度 = 提示框宽度） |
| 展开方向 | 按钮提示向下、书名提示向上 | 按钮在封面顶部，向下有 ~180px 余量；书名在卡片底部，向下会压住相邻行卡片，向上落在封面内 |
| 最长文案对齐 | 移除钮提示右缘对齐锚点右缘，其余水平居中于锚点 | 「从文库移除」约 80px、半宽 40px > 按钮中心到卡片右缘 27px，居中会溢出卡片；右对齐后与按钮右缘齐平 |
| 书名提示宽度 | `maxWidth = 锚点宽度`（142px），`word-break: break-word` 折行 | 书名可达 20 字以上，限宽后多行向上生长，左右天然不越出卡片 |
| 文案单源 | 按钮用模块常量（`MOVE_LABEL` / `RENAME_LABEL`）供 `aria-label` 与浮层文本共用 | 一句话两处引用同一常量，避免视觉文案与读屏名称漂移；`removeLabel` 已是 prop，直接复用 |
| 出现延迟 | 350ms 后 140ms 淡入 + 2px 位移 | macOS 原生约 1s、Windows 约 500ms；按钮自身有 180ms 淡入 + 20/40ms 错峰，350ms 起跳不抢入场 |
| 消失时机 | 立即（100ms 淡出）；按钮按压、滚动、缩放时立即收起 | 系统 tooltip 移出即消失；按压 `scale(0.94)` 与滚动都会让浮层与锚点错位 |
| 箭头 / 圆角 / 字号 | 无箭头、6px、12.5px | macOS help tag 无箭头；6/8/12 与 `--radius: 8px`、卡片 12px 形成圆角阶 |
| 层叠 | `z-index: 40` | 高于 `.page-head`（10）与图表 tooltip（30），低于对话框（100）与 toast（200） |

## 四、交互口径与边界防护

### 4.1 状态与节奏

延迟由 `setTimeout(350)` 控制，淡入淡出交给 Vue `<Transition name="card-tip">`（不再用 CSS `transition-delay`，避免父级按钮的 20/40ms 错峰 delay 污染）。

| 阶段 | 状态 | 表现 |
|------|------|------|
| 静止 | `visible=false`、`shown=false` | 浮层不渲染，DOM 中无节点、无监听 |
| 触发（`pointerenter` / `focus-visible`） | `visible=true` | 启动 350ms 定时器；计时内移出则清除，不出现 |
| 计时到点 | `shown=true` | 先渲染在 `top/left: -9999px` 完成测量，同一微任务内写入真实坐标，随后进场 |
| 进场 | `card-tip-enter-active` | `opacity 0 → 1`、`translateY(±2px) → 0`，`0.14s cubic-bezier(0.22, 0.8, 0.24, 1)` |
| 移出 / 失焦 / 按压 | `visible=false` | `shown=false` 立即开始 `0.1s ease` 淡出 |
| 滚动（含网格内滚动）/ 窗口缩放 | `emit('dismiss')` | 卡片侧清空锚点，浮层收起；再次悬停重新计时 |

- 位移方向与出现位置一致：按钮提示自上方 2px 落下（`.app-tip--below`），书名提示自下方 2px 升起（`.app-tip--above`）。
- 指针从 A 按钮滑到 B 按钮时，`pointerleave` 先清空锚点、`pointerenter` 再写入，浮层不会停在旧位置。
- 鼠标点击按钮会触发 `focus` 但不会产生 `focus-visible`：`openActionTip` 内用 `el.matches(':focus-visible')` 过滤，避免点击后提示框残留。
- 触屏设备（`pointerType === 'touch'`）不触发提示。

### 4.2 文案与可访问名称

```html
<!-- 改前：三个按钮与书名都用原生 title -->
<button class="action-btn move-btn" title="移入合集" @click.stop="$emit('move', book.id)">
<div class="title" :title="book.title">{{ book.title }}</div>

<!-- 改后：title 删除；aria-label 由常量 / prop 提供，浮层文本与其同源 -->
<button
  class="action-btn move-btn"
  :aria-label="MOVE_LABEL"
  @click.stop="$emit('move', book.id)"
  @pointerenter="openActionTip($event, MOVE_LABEL, 'center')"
  @pointerleave="closeTip"
  @focus="openActionTip($event, MOVE_LABEL, 'center')"
  @blur="closeTip"
>
  <svg … aria-hidden="true">…</svg>
</button>

<!-- 书名行：hover 即锚点，文案与进度在 openTitleTip 中组装 -->
<div class="card-title-row" @pointerenter="openTitleTip" @pointerleave="closeTip">
  <div class="title">{{ book.title }}</div>
</div>

<!-- 卡片末尾：一个 CardTip 承载全部 5 处提示（同一时刻只显示一个） -->
<CardTip
  :visible="tipAnchor !== null"
  :anchor="tipAnchor"
  :text="tipText"
  :meta="tipMeta"
  :placement="tipPlacement"
  :align="tipAlign"
  :max-width="tipMaxWidth"
  @dismiss="closeTip"
/>
```

脚本常量与状态（`BookCard.vue`）：

```ts
/** 操作按钮文案：aria-label（读屏）与提示框文本共用，避免两处漂移 */
const MOVE_LABEL = '移入合集'
const RENAME_LABEL = '重命名'

// —— 悬停提示框：浮层 Teleport 到 body，避开卡片 3D 倾斜造成的文字重采样 ——
const tipAnchor = ref<HTMLElement | null>(null)
const tipText = ref('')
const tipMeta = ref('')
const tipPlacement = ref<TipPlacement>('below')
const tipAlign = ref<TipAlign>('center')
const tipMaxWidth = ref<number | undefined>()
```

- 三个按钮内只有 `aria-hidden="true"` 的 SVG，删除 `title` 后必须由 `aria-label` 承担可访问名称，否则按钮变成无名按钮。
- 浮层 `aria-hidden="true"`：按钮的 `aria-label` 已提供名称；书名提示会重复书名行文本、进度环已有 `aria-label`，不隐藏会被读屏重复朗读。
- `aria-label` 不触发原生 tooltip，浮层元素游离在卡片外且无 `title`，因此不会双弹。

### 4.3 边界场景防护

| 场景 | 处理 |
|------|------|
| 卡片未 hover（按钮 `opacity: 0`） | 按钮仍在 DOM 中且可命中；提示由 `pointerenter` 驱动，`pointer-events` 未变，行为与改造前一致 |
| 按钮按压 | `@pointerleave` 之外的 `:active` 不额外处理：按压时手指 / 指针仍在按钮内，浮层可能残留约 0.1s；由按钮 `@click.stop` 关闭卡片菜单，不拦截业务 |
| 鼠标快速划过按钮 / 书名 | 350ms 定时器未到点即被 `pointerleave` 清除，不出现；无「排队补播」 |
| 点击按钮后按钮仍持有焦点 | `focus` 处理器判断 `:focus-visible`：鼠标点击不匹配，不显示 |
| 长书名（20 字以上） | 浮层 `width = 书名行宽 142px` + `white-space: normal` + `word-break: break-word` 折行，高度向上生长，左右不越出卡片 |
| 超长书名（40 字以上，折行 ≥ 5 行） | 浮层 `top` 被 `resolveTipPosition` 钳制到视口 8px 边距内，可能覆盖卡片上半部，仍完整可读、不产生滚动条 |
| 无进度的书卡 | `progressPercent === null` → `tipMeta` 为空串 → 不渲染进度行，浮层为单行书名 |
| 书名与按钮提示的边界 | 两者锚点不同、同一时刻只有一个 `CardTip` 显示，不会同屏出现 |
| 网格最左 / 最右列 | 浮层是 `body` 的 fixed 子元素，完全不参与 `.book-grid` 的滚动区域计算；水平位置再由 `margin: 8` 钳制，贴边时向内收，不会越出视口 |
| 卡片 3D 倾斜中（v2） | 浮层已脱离 3D 层，文字不参与倾斜重采样；坐标取显示瞬间的 `getBoundingClientRect()`（含变换后的实际位置），倾斜 ≤6° 时与按钮的视觉偏差 < 2px |
| 浮层显示期间指针继续移动（卡片继续倾斜） | 不做逐帧跟随：锚点位移 ≤3px，肉眼不可辨；滚动 / 缩放则直接收起，避免明显错位 |
| 相邻卡片也在 hover | 不可能同时 hover 两张卡；浮层 z-index 40 高于所有卡片 |
| 系统开启「减弱动态效果」 | 保留 350ms 延迟与透明度过渡，只去掉位移 |
| 触屏 / 无 hover 设备 | `pointerType === 'touch'` 直接 return；按钮组本身也依赖 hover 显示，与改造前一致 |
| 深色主题 | `--tip-*` 切到深底白字；材质无模糊，不存在主题差异 |
| 组件卸载 / 路由跳转 | `onBeforeUnmount` 清定时器、摘 `scroll`/`resize` 监听；`Teleport` 节点随组件销毁 |
| 提示框遮挡封面 | 按钮提示落在封面上部；书名提示覆盖封面底部约 20~55px；均 `pointer-events: none`，不拦截封面点击 |

### 5.2 `src/services/cardTip.ts`（新增）

浮层定位的唯一算法入口，纯函数、无 DOM 依赖：

```ts
// 卡片悬停提示框定位：锚点矩形 + 浮层尺寸 → fixed 坐标（纯函数）
// 对应设计文档 specs/图书卡片提示框苹果风美化设计方案-20261021.md §5.2

/** 浮层相对锚点的展开方向 */
export type TipPlacement = 'above' | 'below'

/** 浮层水平对齐方式：居中于锚点 / 右缘对齐锚点右缘 */
export type TipAlign = 'center' | 'right'

/** 视口坐标下的锚点矩形（getBoundingClientRect 的裁剪版） */
export interface TipAnchorRect {
  top: number
  left: number
  width: number
  height: number
}

export interface TipPositionInput {
  anchor: TipAnchorRect
  /** 浮层实测宽度 */
  tipWidth: number
  /** 浮层实测高度 */
  tipHeight: number
  placement: TipPlacement
  align: TipAlign
  /** 浮层与锚点间距，默认 7 */
  gap?: number
  /** 与视口的安全边距，默认 8 */
  margin?: number
  viewportWidth: number
  viewportHeight: number
}

export interface TipPosition {
  top: number
  left: number
}

/** 计算浮层 fixed 坐标：方向由 placement 决定，水平按 align 对齐后收敛到视口内 */
export function resolveTipPosition(input: TipPositionInput): TipPosition {
  const gap = input.gap ?? 7
  const margin = input.margin ?? 8
  const rawLeft =
    input.align === 'right'
      ? input.anchor.left + input.anchor.width - input.tipWidth
      : input.anchor.left + input.anchor.width / 2 - input.tipWidth / 2
  const rawTop =
    input.placement === 'below'
      ? input.anchor.top + input.anchor.height + gap
      : input.anchor.top - gap - input.tipHeight
  return {
    top: clamp(rawTop, margin, input.viewportHeight - margin - input.tipHeight),
    left: clamp(rawLeft, margin, input.viewportWidth - margin - input.tipWidth),
  }
}

/** 收敛到 [min, max]；区间反向收缩（浮层比视口还大）时退回 min */
function clamp(value: number, min: number, max: number): number {
  if (max < min) return min
  return Math.min(Math.max(value, min), max)
}
```

设计取舍：
- 只做钳制、不做方向翻转（`placement` 为调用方意图，空间不足时贴边而非换边）：卡片网格上方始终有页头空间，书名提示向上不会越界；翻转会让浮层跑到书名下方压住下一行。
- 坐标由调用方 `Math.round` 取整，避免半像素导致的文字发虚（浮层虽已脱离 3D 层，半像素定位仍会触发重采样）。

```vue
  }

  else removeViewportListeners()

  await nextTick()
  const anchor = props.anchor
  const el = tipEl.value
  if (!anchor || !el) return
  const rect = anchor.getBoundingClientRect()
  const { top, left } = resolveTipPosition({
    anchor: { top: rect.top, left: rect.left, width: rect.width, height: rect.height },
    tipWidth: el.offsetWidth,
    tipHeight: el.offsetHeight,
    placement: props.placement,
    align: props.align,
    viewportWidth: window.innerWidth,
    viewportHeight: window.innerHeight,

    top: `${Math.round(top)}px`,
    left: `${Math.round(left)}px`,
    ...(props.maxWidth != null ? { width: `${props.maxWidth}px` } : {}),
  }
}

  if (showTimer) {
    clearTimeout(showTimer)
    showTimer = null
  }
}

  emit('dismiss')
}

  window.addEventListener('scroll', onViewportChange, true)
  window.addEventListener('resize', onViewportChange)
}

function removeViewportListeners() {
  window.removeEventListener('scroll', onViewportChange, true)
  window.removeEventListener('resize', onViewportChange)
}

onBeforeUnmount(() => {
  clearTimer()
  removeViewportListeners()
})
</script>
```

```ts
import CardTip from '../ui/CardTip.vue'
import type { TipAlign, TipPlacement } from '../../services/cardTip'

/** 操作按钮文案：aria-label（读屏）与提示框文本共用，避免两处漂移 */
const MOVE_LABEL = '移入合集'
const RENAME_LABEL = '重命名'

// —— 悬停提示框：浮层 Teleport 到 body，避开卡片 3D 倾斜造成的文字重采样 ——
const tipAnchor = ref<HTMLElement | null>(null)
const tipText = ref('')
const tipMeta = ref('')
const tipPlacement = ref<TipPlacement>('below')
const tipAlign = ref<TipAlign>('center')
const tipMaxWidth = ref<number | undefined>()

/** 写入提示状态；同一时刻只允许一个浮层，直接整体覆盖 */
function openTip(
  anchor: HTMLElement,
  options: {
    text: string
    meta?: string
    placement: TipPlacement
    align: TipAlign
    maxWidth?: number
  }
) {
  tipAnchor.value = anchor
  tipText.value = options.text
  tipMeta.value = options.meta ?? ''
  tipPlacement.value = options.placement
  tipAlign.value = options.align
  tipMaxWidth.value = options.maxWidth
}

function closeTip() {
  tipAnchor.value = null
}

/** 操作按钮提示：向下展开；触屏无 hover 语义，鼠标点击不产生 focus-visible，两处都要过滤 */
function openActionTip(event: PointerEvent | FocusEvent, text: string, align: TipAlign) {
  if (event instanceof PointerEvent && event.pointerType === 'touch') return
  const el = event.currentTarget as HTMLElement
  if (event.type === 'focus' && !el.matches(':focus-visible')) return
  openTip(el, { text, placement: 'below', align })
}

/** 书名提示：向上展开，宽度锁定为书名行宽；有进度时补第二行 */
function openTitleTip(event: PointerEvent) {
  if (event.pointerType === 'touch') return
  const el = event.currentTarget as HTMLElement
  openTip(el, {
    text: props.book.title,
    meta: progressPercent.value !== null ? `阅读进度 ${progressPercent.value}%` : '',
    placement: 'above',
    align: 'center',
    maxWidth: el.offsetWidth,
  })
}
```

scoped 样式：**删除**原 `.action-tip` 全部规则与 `.action-btn { position: relative }`（浮层已不是按钮子元素）；卡片侧不新增任何提示框样式。

实现注意：

1. `.card-title-row` 替换原 `.title` 成为 `.tilt-card` 的 flex 子项，`gap: 6px` 间距不变；`.title` 的 `overflow: hidden` + 省略号规则原样保留，只删 `:title` 绑定。
2. `openTip` 用 `event.currentTarget` 取锚点：`pointerenter` 与 `focus` 的 `currentTarget` 都是绑定的元素本身，不受子元素影响。
3. `tipAnchor` 既作「是否触发」又作锚点：`visible = tipAnchor !== null`，无需第二个布尔量。
4. `remove-btn` 的 `align` 传 `'right'`，其余传 `'center'`；书名固定 `'above' + 'center' + maxWidth`。
5. 提示框不再依赖 `:hover` 选择器，卡片倾斜、按钮 `opacity` 过渡、`scale(0.94)` 按压都不会影响浮层外观。

```ts
  tipText.value = props.collection.title
  tipMaxWidth.value = el.offsetWidth
}

function closeTip() {
  tipAnchor.value = null
}
```

- 删除原 `.title` 上的 `:title="collection.title"`，其余样式（13px / 单行省略）不动。
- 不写任何新样式：`.card-title-row` 由 `src/style.css` 提供，浮层样式在 `CardTip.vue` 内。
- 文件头注释追加一句「书名提示走 CardTip 浮层，对应设计文档 §5.6」。

## 十、风险与取舍记录

| 项 | 取舍 | 影响与备注 |
|----|------|------------|
| **3D 层重采样（v2 主因）** | 浮层 `Teleport` 到 `body`，脱离 `.tilt-card` | 这是唯一能彻底解决「hover 模糊、Tab 锐利」的办法：子元素无法逃出父级 3D 层的栅格化。代价是 DOM 里多一层 Teleport 与一份定位脚本 |
| **不透明底放弃毛玻璃** | 半透明会让浏览器关闭子像素抗锯齿 → 小字发虚 | 0.94 不透明度下 `blur(16px)` 本就几乎不可见，视觉损失极小；若后续要恢复质感，需同步接受锐度下降 |
| **定位不逐帧跟随** | 显示瞬间测量一次 | 浮层显示后指针继续移动会让卡片继续倾斜，锚点位移 ≤3px，肉眼不可辨；滚动 / 缩放直接收起，避免明显错位 |
| **滚动即收起** | 不做跟随重定位 | 与系统 tooltip 一致；实现零成本（收 `dismiss` 事件），避免每帧 `getBoundingClientRect` |
| 书名提示常显 | 不判断是否截断（用户确认） | 书名未截断时也会弹出与行内相同的文本，略冗余；若后续觉得吵，可加 `pointerenter` 时测量 `scrollWidth > clientWidth` 再决定是否 `openTip` |
| 进度并入书名框 | 取消进度环独立提示（用户确认） | 进度信息需悬停书名行才可见，发现性弱于原先直接看环；环本身仍常驻显示百分比数字，信息不丢 |
| 浅色主题 + 浅色封面 | 近白底 `#fbfbfd` 靠 `1px rgba(0,0,0,0.08)` 描边与投影分离 | 极端浅色封面上对比偏弱；若验收觉得不够，把 `--tip-border` 提到 `rgba(0,0,0,0.14)`（单点令牌） |
| 书名提示上限 142px | 与书名行同宽、折行而非加宽 | 超长书名会变成 3~4 行提示框（向上覆盖封面底部约 55px），40 字以上会被视口钳制并覆盖部分封面，仍可读、不产生滚动条 |
| 定位只钳制不翻转 | `placement` 为调用方意图，空间不足时贴边 | 卡片网格上方始终有页头空间，书名向上不会越界；翻转会让浮层压住下一行卡片，更差 |
| 延迟 350ms | 介于 macOS（~1s）与 Windows（~500ms）之间 | 快速扫视按钮 / 书名时不会连闪；偏慢可把 `CardTip` 的 `delay` 默认值统一改为 `250` |
| 文案两处引用同一常量 | `MOVE_LABEL` / `RENAME_LABEL` 常量 + `removeLabel` prop | 视觉文案与读屏名称不会漂移；提示文本由事件处理器传入，模板里不再出现重复文案 |
| 每卡一个 `CardTip` | 5 个触发源共用一个浮层实例 | 100 张卡片 = 100 个空壳组件（浮层不渲染时不产生 DOM、不挂监听）；换来「同一时刻只可能一个提示」的天然约束 |
| 触屏无提示框 | 提示框依赖 hover / focus-visible | 与改造前一致（按钮组本身也依赖 hover 才显示），不引入新问题 |
| 未新增依赖 | 不引入 `@floating-ui` 等定位库 | 符合工程红线；8 条纯函数用例覆盖本期全部场景，将来需要翻转 / 箭头再评估 |
