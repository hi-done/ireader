# 设置页与文库下拉菜单苹果风格美化设计方案

> 状态：设计稿（v1.2.6 已实现；含阅读页顶栏扩展）
> 目标版本：v1.2.6（沿用当前 package.json 版本，本次不改版本号、不打 tag，由用户自行发版时确定）
> 范围：设置页 3 个下拉（默认阅读模式 / 默认阅读方向 / 主题）、文库页「排序方式」下拉、阅读页顶栏缩放下拉（PDF / EPUB）——触发器图标与弹层内容统一为 macOS 弹出按钮 + 菜单观感
> 实现约束：遵循 `ireader-dev-tasks`（任务 D：渲染层组件归属与样式主题兼容；任务 F：验证流程）与 `ireader-code-conventions`（中文注释、纯逻辑入 `src/services/`、Vitest 只测纯逻辑、不新增依赖）

## 一、需求拆解与验收标准

| # | 原始需求 | 设计落点 | 验收方式 |
|---|----------|----------|----------|
| 1 | 设置页下拉菜单图标美化 | 触发器右侧由系统原生单三角改为 SF Symbols 风格 `chevron.up.chevron.down` 双箭头（内联 SVG、`currentColor`、1.5px 描边），并随 hover / 展开态变深 | 三个设置下拉与文库排序下拉的箭头形态一致；默认 `--text-muted`、hover / 展开 `--text-secondary`，深浅主题自动适配 |
| 2 | 设置页下拉菜单内容美化 | 自绘弹层：10px 圆角、`--surface-alpha` 毛玻璃、菜单级阴影、30px 圆角菜单项、选中项左侧勾选 | 点击触发器弹出：弹层背景半透明可见底层模糊、边缘圆角、阴影自然、选中项有蓝色对勾 |
| 3 | 弹出菜单符合苹果系统风格 | 悬停 / 键盘高亮为品牌蓝圆角填充 + 白字；开合 120ms 缩放淡入；展开态触发器蓝色描边 + 柔光环；深浅主题共用设计令牌 | 悬停任意菜单项为蓝底白字；键盘方向键高亮同步；展开/收起动效无跳变；深色主题下弹层为深色半透明 |
| 4 | 不改变数据与交互语义 | 设置项仍走 `v-model` + `change` → `settingsStore.patch`（SQLite）；文库排序仍 `v-model="library.sortBy"` → store watch 写 localStorage | 选择后离开设置页再进入、重启应用，值均保持；文库排序选择后图书立即重排，重启后偏好保持 |
| 5 | 键盘与读屏可用（自绘组件必须补齐的能力） | 按 WAI-ARIA「select-only combobox」实现：角色、`aria-expanded` / `aria-activedescendant`、方向键 / Home / End / Enter / Space / Esc / Tab | 纯键盘完成开合与选择；Esc 关闭不改值；Tab 关闭并自然移焦；读屏能播报当前值与选中项 |
| 6 | 阅读页顶栏下拉同风格（用户追加） | 复用 `SelectMenu`：泛型放宽到 `T extends string \| number` 承载缩放 / 字号数值档位；外观经 `--select-*` 变量覆盖为深色顶栏变体（透明底、半透明白描边、4px 圆角、26px 高）；PDF 为「适宽 / 适高 / 原始 / 自定义 %」，EPUB 为缩放或字号档位 + 档位外自定义值 | 阅读页两个下拉与相邻按钮同高、同描边；展开为毛玻璃弹层 + 蓝底白字；选择后缩放 / 字号立即生效并持久化；菜单展开期间顶栏不自动隐藏，方向键不触发翻页 |

**核心验收口径**：设置页 3 个下拉、文库排序下拉与阅读页 2 个下拉在浅色 / 深色主题下，触发器与弹层逐项符合 §6.2 / §6.3 规格（阅读页触发器为深色顶栏变体，见 §6.2）；鼠标与键盘两条路径均可完成选择且值持久化正确；`npm run typecheck`、`npm test` 通过，其余页面视觉零变化。

## 二、非目标（本期不做）

- 不引入第三方 UI 组件库或图标库（如 Element Plus、lucide）：纯离线红线 + 「不新增依赖」约束，图标一律内联 SVG。
- 不做菜单项前置图标（每项配太阳 / 月亮等）：macOS 弹出按钮菜单默认无图标，保持克制；如后续需要，在 `SelectOption` 上扩展 `icon` 字段即可。
- 不做输入型筛选（type-ahead）、分组、分隔线、子菜单、多选：当前选项最多 3 项，超出收益。
- 不改「阅读时间统计」入口行右侧的跳转 chevron（非下拉菜单）、不改设置页其余行控件与 `group-card` 结构。
- 不改 `CollectionPickerDialog` 等对话框内的列表按钮（非下拉菜单）。
- 不改全局 `input, select` 表单样式与按钮三级体系；替换后全局 `select` 规则暂无消费方，保留不删（避免范围外改动）。
- 不新增 / 修改设置项、IPC 通道、DB 表结构、共享类型。
- 不改造为 Electron 原生 `Menu.popup`：原生菜单外观随操作系统变化，Windows 下无法呈现苹果风格，且需新增 IPC 能力。

## 三、总体设计

### 3.1 结构与数据流

```
SettingsView.vue                         LibraryView.vue
  form.defaultMode / defaultDirection /    library.sortBy
  form.theme（reactive 副本）              （Pinia store ref）
        │  v-model / @change                      │  v-model
        └──────────────┬──────────────────────────┘
                       ▼
        components/ui/SelectMenu.vue（新增，通用自绘下拉）
          ├─ 触发器 button[role=combobox]
          │    ├─ 当前值文本（selectedLabel）
          │    └─ 双箭头内联 SVG（aria-hidden）
          └─ 弹层 ul[role=listbox]（position: fixed，z-index 50）
               ├─ li[role=option] × N：勾选槽位 + 文案
               └─ 交互：点选 / 悬停 / 方向键 / Home / End / Esc / Tab
                       │
                       ▼
        纯逻辑 services/selectMenu.ts（新增）
          ├─ initialActiveIndex / moveActiveIndex（高亮下标）
          └─ resolveMenuPlacement / clampMenuLeft（翻转与横向收敛）

数据出口不变：
  SettingsView  @change → settingsStore.patch → ipc.settings.patch → SQLite settings 表
  LibraryView   v-model → library store watch → localStorage('ireader.sort')（纯 UI 偏好）
```

无 IPC、无 DB、无共享类型改动；纯渲染层组件 + 纯逻辑模块。

### 3.2 关键决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 实现方式（用户确认） | 自绘 `SelectMenu` 组件 | 原生 `<select>` 弹层由系统绘制，无法定制圆角 / 毛玻璃 / 勾选 / 高亮；`appearance: base-select` 虽保留原生行为，但弹层材质与动效能力受限且需实测，无法稳定达成苹果观感 |
| 高亮风格（用户确认） | 系统蓝底白字 + 选中勾选 | 最接近 macOS 菜单的高亮语义；浅灰方案在高亮与选中之间缺少区分 |
| 作用范围（用户确认） | 设置页 3 个 + 文库排序 1 个；阅读页顶栏 2 个（后续追加） | 同一组件替换，避免应用内两种下拉形态并存；文库页仅换控件，排序逻辑与持久化不动 |
| 弹层渲染方式（随自绘方案派生） | Teleport 到 body + `position: fixed` + 滚动 / 缩放重算坐标 | 弹层原位于 `.settings-view`（`overflow-y: auto`）与文库 `.toolbar`（`backdrop-filter` 会成为 fixed 包含块）内，留在原地会被裁切或坐标错位；Teleport 到 body 后始终相对视口定位 |
| 深色顶栏适配（阅读页派生） | 触发器外观全部走 `--select-*` CSS 变量，由 `.zoom-select` 覆盖为透明底 + 白描边；不新增 `variant` 分支 | 阅读页顶栏是恒定深色材质，与设置页浅色表单控件观感相反；变量覆盖只改视觉、不改组件逻辑，弹层仍随浅 / 深主题 |
| 宿主快捷键冲突（阅读页派生） | 组件消费的按键 `preventDefault` + `stopPropagation` | 两个阅读页都在 window 上监听方向键 / Enter 翻页与全屏快捷键；不阻止冒泡会「移动高亮的同时翻页」 |
| 顶栏自动隐藏（阅读页派生） | 组件对外 emit `open` / `close`，阅读页用 `barsPinned` 标志锁定顶栏：展开期间 `showBarsTemporarily` 只保持可见、不启动隐藏计时，收起后再恢复计时 | 只清一次 `hideTimer` 不够：鼠标在触发器附近移动会反复调用 `showBarsTemporarily` 重新计时，1.5~3 秒后顶栏照常淡出，菜单还开着触发器就消失 |
| 样式归属 | 组件 scoped 样式 + `style.css` 新增 `--menu-shadow` | 组件样式局部内聚；阴影需随深浅主题变化，走全局令牌而非组件内媒体查询 |
| 纯逻辑归属 | 抽到 `src/services/selectMenu.ts` 并补单测 | 项目约定纯逻辑入 services、Vitest 只测纯逻辑；下标移动与翻转计算可脱离 DOM 验证 |
| 组件类型 | `<script setup generic="T extends string \| number">` | 让 `v-model` 在 `ReadingMode` / `Direction` / `SortBy` / `ZoomMode` 等字面量联合与阅读页百分比数值档位上保持类型安全，避免视图侧 `as` 断言 |

## 四、核心算法与交互口径

### 4.1 键盘与开合状态机

| 场景 | 按键 / 事件 | 行为 |
|------|-------------|------|
| 关闭态 | `ArrowDown` / `ArrowUp` / `Enter` / `Space` | 阻止默认；展开弹层，高亮定位到当前选中项（未匹配时取第 0 项） |
| 关闭态 | 点击触发器 | 展开，同上定位 |
| 展开态 | `ArrowDown` / `ArrowUp` | 循环移动高亮（首尾回绕），阻止默认 |
| 展开态 | `Home` / `End` | 高亮首项 / 末项 |
| 展开态 | `Enter` / `Space` | 提交高亮项并关闭，焦点回到触发器，阻止默认 |
| 展开态 | `Escape` | 关闭、不提交，焦点回到触发器 |
| 展开态 | `Tab` | 关闭、不提交，不拦截焦点移动 |
| 展开态 | 点击选项 | 提交该项并关闭，焦点回到触发器 |
| 展开态 | 点击组件外部（`pointerdown` 捕获阶段） | 关闭、不提交 |
| 展开态 | 触发器再次点击 | 关闭、不提交 |
| 任意态 | 组件卸载 / 关闭 | 移除 document 与 window 监听，避免泄漏 |

> 组件消费的按键（方向键 / Home / End / Enter / Space / Esc）统一 `preventDefault` + `stopPropagation`：两个阅读页都在 `window` 上监听方向键翻页，不阻止冒泡会「移动高亮的同时翻页」；`Tab` 只关闭弹层，保留焦点移动。

提交口径：仅当选中值与 `modelValue` 不同才依次 emit `update:modelValue` → `change`（与原生 `change` 语义一致，重复选择同一项不触发保存）。`SettingsView` 的 `@change="save"` 依赖「先更新 `form` 再执行保存」，因此组件内必须先 emit `update:modelValue`。

### 4.2 定位与翻转

```ts
// 纯函数签名（src/services/selectMenu.ts）
export function initialActiveIndex<T extends string | number>(
  options: readonly SelectOption<T>[],
  value: T
): number

export function moveActiveIndex(current: number, delta: -1 | 1, count: number): number

export interface MenuPlacementInput {
  triggerTop: number
  triggerBottom: number
  menuHeight: number
  viewportHeight: number
  gap?: number // 触发器与弹层间距，默认 6
  margin?: number // 视口安全边距，默认 8
}
export function resolveMenuPlacement(input: MenuPlacementInput): 'below' | 'above'

export function clampMenuLeft(
  preferredLeft: number,
  menuWidth: number,
  viewportWidth: number,
  margin?: number
): number
```

实现口径：

```ts
// 展开后 nextTick 测量弹层尺寸，再写内联坐标
const rect = trigger.getBoundingClientRect()
const placement = resolveMenuPlacement({
  triggerTop: rect.top, triggerBottom: rect.bottom,
  menuHeight: menu.offsetHeight, viewportHeight: window.innerHeight,
})
const top = placement === 'below' ? rect.bottom + 6 : rect.top - 6 - menu.offsetHeight
const left = clampMenuLeft(
  rect.right - menu.offsetWidth, menu.offsetWidth,
  document.documentElement.clientWidth
)
// 右边缘对齐触发器；翻转时 transform-origin 取 bottom right，否则 top right

// resolveMenuPlacement 口径
spaceBelow = viewportHeight - triggerBottom - margin
spaceAbove = triggerTop - margin
spaceBelow >= menuHeight + gap ? 'below'
  : spaceBelow >= spaceAbove ? 'below' : 'above'
```

- 弹层经 `Teleport` 渲染到 body，`position: fixed`、`z-index: 50`（高于吸顶页头 10，低于对话框 100 / toast 200）。
- 展开期间监听 `window` 的 `scroll`（捕获阶段，覆盖 `.settings-view` 内部滚动）与 `resize`，实时重算坐标；关闭时移除。
- 弹层 CSS 固定 `min-width: 160px`，避免首次测量与内联最小宽度互相影响造成二次重排。

### 4.3 边界场景防护

| 场景 | 处理 |
|------|------|
| `options` 为空 | 触发器可聚焦但点击 / 按键不展开；高亮下标保持 -1 |
| `modelValue` 不在 `options` 中 | 触发器回退显示原始值字符串；展开高亮定位第 0 项 |
| 重复选择当前项 | 仅关闭，不 emit，不触发保存 |
| 视口下方空间不足 | 向上展开；上下均不足时取空间较大侧，相等时向下 |
| 窗口极窄 / 弹层右对齐越界 | `clampMenuLeft` 收敛到左右各 8px 安全边距内 |
| 页面滚动 / 窗口缩放 | scroll / resize 时重算坐标，弹层跟随触发器 |
| 用户快速连点触发器 | 以 `open` 状态为准切换；关闭先清理监听，重复调用幂等 |
| 深色主题切换时弹层打开 | 颜色全走 CSS 变量，无需重建；主题切换会触发重新渲染 |
| 系统开启「减弱动态效果」 | `prefers-reduced-motion: reduce` 下取消开合过渡 |
| 触发器禁用 | `disabled` prop 透传原生 disabled，点击 / 键盘均不展开 |

## 五、渲染层实现

### 5.1 新增通用组件 `src/components/ui/SelectMenu.vue`

归属说明：`components/` 现有 `library`、`stats` 两个功能域，通用交互控件新建 `ui` 域；不使用 `library/` 以免通用组件反向依赖业务域。

对外契约：

```ts
<script setup lang="ts" generic="T extends string | number">
import type { SelectOption } from '../../services/selectMenu'

defineProps<{
  modelValue: T
  options: SelectOption<T>[]
  /** 读屏名称：行内可见标签不属于按钮文本，需显式提供（如「默认阅读模式」）；
      不命名 ariaLabel（组件上的 aria-* 属性不会映射到驼峰 prop），由模板拼进 aria-label */
  label: string
  /** 原生 title 提示：阅读页顶栏沿用「缩放 / 字号」悬停说明 */
  title?: string
  disabled?: boolean
}>()

defineEmits<{
  'update:modelValue': [value: T]
  change: [value: T]
  /** 展开 / 收起：宿主据此暂停自动隐藏工具栏等定时逻辑（阅读页顶栏） */
  open: []
  close: []
}>()
</script>
```

模板骨架（关键属性，实施时按此落地）：

```html
<div ref="rootEl" class="select-menu">
  <button
    ref="triggerEl"
    type="button"
    class="select-trigger"
    role="combobox"
    aria-haspopup="listbox"
    :aria-expanded="open"
    :aria-controls="listId"
    :aria-activedescendant="open && activeIndex >= 0 ? optionId(activeIndex) : undefined"
    :aria-label="`${label}：${selectedLabel}`"
    :title="title"
    :disabled="disabled"
    @click="toggle"
    @keydown="onTriggerKeydown"
  >
    <span class="select-value">{{ selectedLabel }}</span>
    <svg class="select-chevron" width="9" height="12" viewBox="0 0 9 12" aria-hidden="true">
      <path d="M1.5 4.5 4.5 1.5 7.5 4.5M1.5 7.5 4.5 10.5 7.5 7.5"
            fill="none" stroke="currentColor" stroke-width="1.5"
            stroke-linecap="round" stroke-linejoin="round" />
    </svg>
  </button>

  <Teleport to="body">
    <Transition name="select-pop">
      <ul
        v-if="open"
        ref="menuEl"
        :id="listId"
        class="select-pop"
        role="listbox"
        :aria-label="label"
        :style="menuStyle"
        @pointerdown.prevent
      >
        <li
          v-for="(option, index) in options"
          :id="optionId(index)"
          :key="option.value"
          role="option"
          class="select-option"
          :class="{ 'is-selected': option.value === modelValue, 'is-active': index === activeIndex }"
          :aria-selected="option.value === modelValue"
          @mouseenter="activeIndex = index"
          @pointerdown.prevent
          @click="commit(option)"
        >
          <svg class="select-check" width="14" height="14" viewBox="0 0 14 14" aria-hidden="true">
            <path d="M2.5 7.5 5.5 10.5 11.5 3.5" fill="none" stroke="currentColor"
                  stroke-width="1.8" stroke-linecap="round" stroke-linejoin="round" />
          </svg>
          <span class="select-option-label">{{ option.label }}</span>
        </li>
      </ul>
    </Transition>
  </Teleport>
</div>
```

实现要点：

1. `open`、`activeIndex`、`menuStyle` 用 `ref`；`triggerEl` / `menuEl` / `rootEl` 用于测量与外部点击判定。
2. 展开流程：置 `open = true` → `await nextTick()` → 测量并写入 `menuStyle` → 注册 `pointerdown`（document，捕获）、`scroll`（window，捕获）、`resize`（window）。
3. 关闭流程：置 `open = false` → 移除上述监听；按需 `triggerEl.focus()`（提交 / Esc 时恢复焦点，外部点击 / Tab 不恢复）。
4. `listId` / `optionId` 用模块级自增序号生成（`<script setup>` 顶层代码按实例执行，计数器必须放在普通 `<script>` 块声明的模块作用域，否则同页多个下拉 id 重复）；依赖声明为 `vue ^3.4.21`，不复用仅 3.5 提供的 `useId`。
5. 弹层 `Teleport to="body"`：文库 `.toolbar` 的 `backdrop-filter` 会成为 `position: fixed` 的包含块，原地渲染会坐标错位；外部点击判定需同时检查 `rootEl` 与 `menuEl`（弹层已不在 rootEl 内）。
6. 弹层根节点与菜单项均加 `@pointerdown.prevent`：点击弹层内边距或选项时不把焦点从触发器移走，保证 Esc / 方向键在任意点击后仍可用。
7. 高亮选项滚动可见：高亮变化后 `menuEl.children[activeIndex]?.scrollIntoView({ block: 'nearest' })`（当前最多 3 项不触发滚动，为后续扩展兜底）。
8. `onBeforeUnmount` 中兜底清理监听；`watch(modelValue)` 不需要同步高亮（弹层在提交时已关闭）。
9. 组件内不访问 IPC / store，完全受控（`modelValue` + emit），便于设置页与文库页复用。

### 5.2 设置页接线 `src/views/SettingsView.vue`

- 三个下拉行由 `<label class="row">` 改为 `<div class="row">`：`label` 会把点击转发给内部按钮，导致点击行标签也展开菜单，与 macOS 设置行语义不符。
- 三处替换：


## 十、风险与取舍记录

| 项 | 取舍 | 影响与备注 |
|----|------|------------|
| 自绘组件需自建无障碍 | 按 WAI-ARIA select-only combobox 实现，并纳入冒烟清单 | 后续 Electron 原生 `appearance: base-select` 材质能力成熟时，可保留组件 API 只换内部实现（扩展点） |
| 蓝底白字对比度 | 白字在 `#007aff` 上对比度约 3.6:1，低于 WCAG AA 4.5:1 | 与 macOS 菜单观感一致的取舍；若需严格达标，把高亮背景换成 `--brand-hover`（一行改动） |
| `position: fixed` 弹层与 Teleport | 弹层经 `Teleport` 渲染到 body，始终相对视口定位 | 文库 `.toolbar` 的 `backdrop-filter` 与设置页滚动容器都不再影响弹层；若未来 body 出现 transform 需重新评估（当前无） |
| 展开期间 scroll / resize 重算 | 每次滚动重算一次坐标，开销可忽略（仅菜单打开时监听） | 关闭与卸载均清理监听，无泄漏 |
| 全局 `select` 样式失去消费方 | 保留不删 | 避免范围外改动；若未来表单复用可直接沿用 |
| 菜单项无前置图标 | 保持 macOS 弹出按钮菜单的原生观感 | 需要时在 `SelectOption` 增加可选 `icon` 字段扩展，不改现有调用 |
| 文库工具栏触发器宽度 | 由 108px 最小宽 + 32px 高替代原生 select | 工具栏高度由搜索框决定，不跳动；尺寸与配色统一抽为 `--select-*` 变量，阅读页深色顶栏即通过覆盖同一组变量实现 |
| 阅读页顶栏自动隐藏 | 组件 emit `open` / `close`，阅读页用 `barsPinned` 锁定 / 解锁顶栏 | 锁定期间任何 `mousemove` 触发的显示都只保持可见；解锁时重新起 3 秒计时。若未来其它宿主也有自动隐藏，可复用同一对事件 |
| 阅读页 window 键盘监听 | 组件对所有消费的按键 `stopPropagation`，只保留 `Tab` 冒泡 | 方向键 / Enter / Esc 不再触发阅读页翻页与快捷键；`Tab` 仍可自然移到下一控件 |
| 深色顶栏上的弹层材质 | 弹层仍走 `--surface-alpha`，跟随应用浅 / 深主题 | 与 macOS 一致：菜单材质跟随系统外观，不跟随触发它的控件；若希望弹层强制深色，可给 `.zoom-select` 追加弹层变量（当前无此变量，属于未来扩展点） |
